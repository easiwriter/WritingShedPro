# Organizing Your Work

A well-organized project makes writing easier and more productive. This guide covers strategies and features for keeping your work organized.

## The Folder Workflow

Writing Shed Pro's folder structure supports a natural writing workflow:

```
Draft → Ready → Submit → Publish
  ↓
Set Aside
  ↓
Trash
```

### Draft
Where new work begins. Use Draft for:
- First drafts
- Work in progress
- Pieces that need revision

### Ready
Move work here when it's polished and complete. Ready signals:
- No more major edits needed
- Ready for submission or publication
- Your best, finished work

### Set Aside
For work you're not actively pursuing:
- Ideas that aren't working yet
- Seasonal pieces (waiting for the right time)
- Experiments you might return to

### Trash
Deleted items land here. You can:
- Restore accidentally deleted work
- Review before permanent deletion
- Empty periodically to clean up

## Using Subfolders

Create subfolders to add another level of organization:

### By Theme or Subject
```
Draft/
├── Nature Poems
├── Love Poems
└── Political Poems
```

### By Form or Style
```
Draft/
├── Sonnets
├── Haiku
└── Free Verse
```

### By Project or Collection
```
Draft/
├── Competition Entry
├── New Chapbook
└── Experiments
```

### By Status
```
Draft/
├── First Draft
├── Needs Revision
└── Almost Ready
```

## Sorting and Ordering

Control how files appear in lists:

### Sort Options
- **Name**: Alphabetical (A-Z)
- **Date Created**: When files were made
- **Date Modified**: When files were last edited
- **User's Order**: Your custom arrangement

### Setting Sort Order
1. Open a folder
2. Tap the sort button in the toolbar
3. Choose your preferred order

### Custom Ordering
1. Set sort to "User's Order"
2. Tap **Edit**
3. Drag files using the handles
4. Tap **Done**

Custom order is saved and syncs across devices.

## Collections

Collections let you group files without moving them. A file can belong to multiple collections.

### Creating a Collection
1. Open the Collections folder
2. Tap **+**
3. Enter a collection name
4. Tap **Create**

### Adding Files to a Collection
1. Navigate to files in Draft or Ready
2. Select one or more files
3. Choose **Add to Collection...**
4. Select the collection

### Collection Uses
- Group poems for a chapbook
- Assemble stories for a themed submission
- Create a reading order for an event
- Organize by publication targets

See [Collections](../10-advanced-features/104-collections.md) for more details.

## Searching

Find files quickly with search:

### Project Search
1. From the project view, tap the search icon
2. Type your search term
3. Results show matching files

### Within a Folder
Search scope is limited to the current folder and its subfolders.

### Search Options
- Search by file name
- Search within file content
- Case-insensitive by default

## Tags and Metadata

While Writing Shed Pro doesn't have explicit tags, you can use:

### Naming Conventions
Add prefixes or suffixes to file names:
- `[WIP] Poem Title` for work in progress
- `Poem Title - Sonnet` for form
- `Poem Title (Contest)` for destination

### Details Field
Use the file details field for notes, tags, or metadata.

## Workflow Examples

### Poetry Workflow
1. New poem → Draft
2. Revise and polish → Still in Draft
3. Complete → Move to Ready
4. Create Collection for submission
5. Submit → Track in Submissions
6. Accepted → Celebrate!

### Novel Workflow
1. Create scenes in Draft
2. Link to plot elements
3. Organize into chapters
4. Move completed chapters to Ready
5. Assemble full manuscript for export

### General Writing Workflow
1. Start in Draft
2. Organize in subfolders by project/topic
3. Move to Ready when done
4. Export or print as needed

## Cleanup and Maintenance

Keep your project healthy:

### Regular Tasks
- Move finished work to Ready
- Archive old work to Set Aside
- Empty Trash monthly
- Review Collections for relevance

### Spring Cleaning
- Delete truly obsolete files
- Consolidate similar folders
- Update file names for clarity
- Archive completed projects

### Before Submitting
- Ensure work is in Ready
- Double-check formatting
- Review in pagination view
- Export and proof
