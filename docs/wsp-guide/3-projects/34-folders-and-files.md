# Folders and Files

Writing Shed Pro organizes your work in a hierarchy of folders and files within each project. This guide explains how to work with both.

## Understanding the Hierarchy

```
Project
└── Folders
    └── Files
```

- **Projects** contain folders
- **Folders** contain your files
- **Files** contain your actual writing

## Workflow Status (Not Folders)

`Draft`, `Ready`, `Set Aside`, and `Published` are **file workflow statuses**, not folders.

In content views, status tabs appear at the top with counts:
- **All**
- **Draft**
- **Ready**
- **Set Aside**
- **Published**

Tap a status tab to filter the file list.

### Changing a File's Workflow Status
1. Open the file list in a content area
2. Tap **Edit**
3. Select one or more files
4. Tap **Change Status** (🔁)
5. Choose the new status

`Published` is set automatically when a submission is accepted.

### Poetry
Additional project folders:
- **Poems**: Your main writing area for poems
- **Collections**: Poetry Collections — group related poems together
- **Submissions**: Track what you've sent
- **Magazines**: Publication targets
- **Competitions**: Contest targets

### Fiction (Novel, Verse Novel, Short Fiction)
Additional project folders:
- **Scenes** (or **Episodes** for Verse Novel): Your story scenes
- **Chapters** (Novel), **Books** (Verse Novel): Organizational containers
- **Plot Elements**: Story beats
- **Characters**: Character profiles
- **Locations**: Setting definitions
- **Submissions**: Track what you've sent
- **Publishers / Agents**: Submission targets

## Creating Files

Create a new file:

1. Open the destination folder
2. Tap the **+** button
3. Select **New File** (or specific type for Poetry/Fiction)
4. Enter a title
5. For Poetry: Optionally select a form template, or tap **Create Custom Form** to define your own
6. Tap **Create**

The file opens automatically in the editor.

### File Types by Project
- **Prose**: Text files
- **Poetry**: Poem files (with optional form)
- **Fiction**: Scene files
- **Drama**: Scene files (with DML support)

## Renaming

Rename files from the **⋯ (ellipsis) button** in the file row.

### Rename a File
1. Tap the **⋯** button for the file
2. In file details, tap **Edit**
3. Enter the new name
4. Tap **Save**

## Reordering Files

Files can be reordered within a folder:

1. Tap **Edit** in the folder view
2. Ensure sort is set to **User's Order**
3. Drag files using the handle on the right
4. Tap **Done**

### Sort Options
- **Name**: Alphabetical order
- **Date Created**: Chronological order
- **Date Modified**: By last edit
- **User's Order**: Your custom arrangement

## Deleting

### Delete a Single File
1. Swipe left on the file row
2. Tap **Delete**

Deleted files go to **Trash** and can be restored.

### Delete Multiple Files
1. Tap **Edit** in the file list
2. Select one or more files
3. Tap **Delete**
4. Confirm



## The Trash

Deleted files aren't immediately destroyed—they go to Trash.

### Restoring from Trash
1. Open the **Trash** folder
2. Find the item you want to restore
3. Swipe left on the item
4. Tap **Put Back**

Items are restored to their original location.

### Emptying Trash
1. Open the **Trash** folder
2. Tap **Empty Trash**
3. Confirm

**Warning**: Emptying Trash permanently deletes all items. This cannot be undone.

## File Details

View information about a file:

1. Tap the **⋯ (ellipsis)** button for the file
2. The details sheet opens

### Information Shown
- File name
- Created date
- Modified date
- Word count
- Character count
- Version history

## Versions

Writing Shed Pro automatically creates versions as you edit:

### Viewing Versions
1. Open file details
2. Tap **Versions**
3. See the version history

### Restoring a Version
1. Tap a version to preview
2. Tap **Restore** to make it current

The current content becomes a new version, so nothing is lost.

## Best Practices

### Regular Cleanup
- Change completed work to **Ready**
- Change paused work to **Set Aside**
- Empty Trash periodically

### Workflow Tips
- Start in **Draft**
- Change to **Ready** when polished
- Use Poetry Collections to group poems for submission (Poetry projects)
- Track submissions through the Submissions folder
