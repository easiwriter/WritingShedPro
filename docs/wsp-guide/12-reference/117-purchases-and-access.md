# Purchases and Access

Writing Shed Pro uses one of two purchase systems. The system shown to you depends on the version of Writing Shed Pro that you originally obtained, not the version currently installed.

## Before Version 19: Legacy Module Purchases

If you originally obtained Writing Shed Pro before version 19, you remain on the legacy purchase system after updating the app.

The legacy system provides limited access before purchase:

- Up to one project of each project type
- Up to one file in each project
- Reading and editing within those limits

You can make a one-time purchase for an individual writing module:

- Prose Writer
- Poetry Writer
- Fiction Writer
- Drama Writer

An individual module purchase removes the project and file limits for that project type. The **All-in Bundle** is a one-time purchase that unlocks all four modules. Existing module and bundle purchases remain valid and can be restored from the Store.

Legacy users are not moved to the version 19 trial system when they update.

## Version 19 and Later: Trial and Full Access

If you first obtain Writing Shed Pro in version 19 or later, you use the Trial and Full Access system.

You can choose either:

- **10-Day Free Trial**: full access to the core writing features for exactly 10 days. It is a one-time trial and does not renew or charge automatically.
- **Writing Shed Pro Full Access**: a one-time purchase that permanently unlocks all core project types and writing features.

You can purchase Full Access without starting the trial first.

When the trial expires, your existing projects and files remain available to read. Creating or changing content, importing, printing, and exporting require Full Access. Your work is not deleted when the trial expires.

## Restoring Purchases

Use **Restore Purchases** in the Store when reinstalling Writing Shed Pro or using another device with the same Apple Account. Restoring does not charge you again.

For legacy users, restoration recovers owned modules or the All-in Bundle. For version 19 and later users, restoration recovers the trial status and Full Access purchase.

## Manuscript Analyst

Manuscript Analyst is a separate subscription and is not included with module purchases, the All-in Bundle, the 10-Day Free Trial, or Full Access.

- Legacy users can subscribe to Manuscript Analyst separately.
- Version 19 and later users must own Full Access before subscribing to Manuscript Analyst. The 10-Day Free Trial alone does not qualify.

Previously generated Analyst reports remain available to read when the subscription is inactive.
