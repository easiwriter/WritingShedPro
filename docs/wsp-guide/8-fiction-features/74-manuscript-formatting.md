# Manuscript Formatting (Fiction)

This guide covers how Writing Shed Pro assembles fiction project content into a manuscript for export. Each fiction class has its own assembly model. For general manuscript structure (front matter, back matter), see [Manuscript Structure](../4-projects/36-manuscript-structure.md).

## How Fiction Manuscripts Are Assembled

### Novel

1. Chapters are assembled in chapter order
2. Scenes within each chapter are combined in scene order
3. Chapter headings are inserted between chapters
4. The result is a single, continuous manuscript

### Verse Novel

1. Books are assembled in book order
2. Episodes within each book are combined in episode order
3. Poetry formatting (line breaks, stanza breaks, indentation) is preserved
4. The result is a continuous verse manuscript

### Short Fiction

1. Scenes are assembled in scene order
2. Scene breaks are inserted between scenes
3. The result is a complete story

### What Gets Included

By default, all scenes are included. You can exclude individual scenes:

1. Open the scene's context menu
2. Toggle **Include in Manuscript** off
3. The scene stays in your project but is skipped during assembly

This is useful for deleted scenes you want to keep, alternate versions, or notes.

## Previewing the Manuscript

Before exporting:

1. Open the **Manuscript** view
2. Check chapter/book breaks appear correctly
3. Verify scene order within each chapter
4. Review formatting
5. Confirm no unwanted scenes are included

## Chapter Headings

Control how chapter headings appear in the manuscript:

| Option | Example Output |
| -------- | --------------- |
| **Number only** | Chapter 1 |
| **Title only** | The Storm |
| **Number and title** | Chapter 1: The Storm |
| **Custom format** | I — The Storm |

### Setting Chapter Headings

1. Open **Export Options** or **Project Settings**
2. Find **Chapter Heading Style**
3. Choose your preferred option

For Verse Novels, book headings follow the same options (e.g., "Book I", "Book I: Origins").

## Scene Breaks

When scenes transition within a chapter, control the separator:

| Break Style | Appearance |
| ------------- | ------------ |
| **Page Break** | Each scene starts on a new page |
| **Section Mark** | Centred symbol (e.g., \* \* \* or §) between scenes |
| **Double Space** | Extra blank line between scenes |
| **None** | Scenes flow together with no visible break |

For most fiction, **Section Mark** (e.g., \* \* \*) is the standard scene break convention. **Page Break** is more common between chapters than between scenes.

## First Paragraph Style

The first paragraph of a chapter or scene can have special formatting:

| Style | Description |
| ------- | ------------- |
| **No indent** | Traditional — first paragraph is flush left |
| **Drop cap** | Decorative large initial letter |
| **Standard indent** | Same indent as all other paragraphs |

Most publishers expect **no indent** for the first paragraph after a chapter heading or scene break.

## Footnote Numbering

Choose how footnotes are numbered across the manuscript:

- **Per File**: Numbering restarts in each scene
- **Continuous**: Sequential numbering across the entire manuscript

## Industry Standard Manuscript Format

For submissions to agents and publishers, standard manuscript format is expected:

### Typical Requirements

- Double-spaced text
- 12pt Courier or Times New Roman
- 1-inch (2.54 cm) margins
- Header with author name, title, and page number
- Word count on the first page
- Scene breaks indicated with # or \* \* \*

### Applying Standard Format

1. Configure your **Stylesheet** for manuscript style (double-spaced, standard font)
2. Set **Page Setup** for Letter or A4 paper with 1-inch margins
3. Set scene break style to **Section Mark**
4. Export to PDF or RTF

## Formatting for Different Purposes

### Agent/Publisher Submission

- Standard manuscript format (above)
- Clean, professional appearance
- Follow specific submission guidelines if provided

### Beta Readers

- Easy-to-read formatting
- Include page numbers
- PDF for consistency across devices

### Self-Publishing

- A starting point — further formatting will be needed
- Platform-specific requirements vary (Kindle, IngramSpark, etc.)

### Personal Review

- Your preference
- Consider larger text for proofing
- Print a paper copy for marking up

## Export Formats

Fiction manuscripts can be exported in all available formats:

| Format | Best For |
| -------- | ---------- |
| **PDF** | Submissions, sharing, print — looks identical everywhere |
| **RTF** | Editor collaboration — editable in Word |
| **HTML** | Web publishing, online sharing |
| **Markdown** | Plain text archives, version control |

See [Export Options](../10-publishing/91-export-options.md) for full details.

## Troubleshooting

### Scenes Out of Order

- Check scene order within the chapter
- Verify chapter order in the Chapters list
- Review in the manuscript preview

### Missing Scenes

- Ensure scenes are assigned to chapters (Novel and Verse Novel)
- Ensure scenes have the correct workflow status
- Check that **Include in Manuscript** is toggled on

### Chapter Breaks Wrong

- Check chapter heading settings
- Ensure chapters are defined and ordered correctly
- Review in pagination view

### Formatting Issues

- Review your stylesheet settings
- Check paragraph styles are applied correctly
- Verify page setup settings
