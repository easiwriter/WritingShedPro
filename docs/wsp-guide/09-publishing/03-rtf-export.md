# RTF Export

RTF (Rich Text Format) produces editable documents compatible with most word processors. Use RTF when you need recipients to be able to edit the content.

## Why RTF?

### Advantages
- **Editable**: Recipients can make changes
- **Compatible**: Opens in Word, Pages, Google Docs, etc.
- **Standard**: Long-established format
- **Lightweight**: Smaller than some alternatives

### When to Use RTF
- Sending to editors who need to make changes
- Collaboration requiring editing
- Importing into other applications
- When PDF isn't accepted

## Exporting to RTF

### Single File
1. Open the file
2. Tap the **Share** or **Export** button
3. Select **Export as RTF**
4. Choose where to save or how to share

### Multiple Files
1. Open the collection, submission, or project
2. Select files to export
3. Choose **RTF**
4. Files export (possibly as separate files or combined)

## What's Preserved in RTF

### Fully Preserved
- Text content
- Bold, italic, underline, strikethrough
- Font family and size
- Paragraph alignment
- Line spacing
- Basic colors

### Usually Preserved
- Images (may resize)
- Footnotes (may format differently)
- Paragraph spacing
- Indentation

### May Vary
- Complex styles
- Advanced typography
- Exact pagination
- Headers/footers

## RTF Limitations

RTF is an interchange format, not a final format:

### Appearance May Differ
- Different apps render RTF differently
- Pagination won't match exactly
- Fonts may substitute if unavailable

### Feature Differences
- Some formatting options don't translate
- Complex layouts may simplify
- App-specific features are lost

### It's a Starting Point
Recipients may need to:
- Adjust formatting
- Set up page layout
- Apply their own styles

## Working with Recipients

### Communicate Expectations
- Let editors know it's RTF
- Mention if specific formatting matters
- Be flexible about final appearance

### Provide Context
- Include any special instructions
- Note if fonts need to be installed
- Explain any unusual formatting

### Accept Changes
RTF is for editing. The document will likely change.

## RTF vs PDF

| Aspect | RTF | PDF |
|--------|-----|-----|
| Editable | Yes | No |
| Appearance | Varies | Fixed |
| File size | Smaller | Larger |
| Features | Some lost | All preserved |
| Use case | Collaboration | Final output |

### Choose RTF When:
- Editors need to make changes
- Importing to another tool
- File size is critical
- PDF isn't an option

### Choose PDF When:
- Appearance must be exact
- Submitting final work
- Protecting content
- Professional presentation

## Troubleshooting RTF

### Formatting Looks Wrong
- Different apps interpret RTF differently
- Try opening in a different app
- Accept that some variation is normal

### Images Missing
- RTF image support varies
- Check export settings
- Try re-inserting images

### File Won't Open
- Check the app supports RTF
- Try a different RTF viewer
- File may be corrupted—re-export

### Fonts Don't Match
- Fonts must be installed on recipient's device
- RTF substitutes if fonts are missing
- Consider using common fonts (Times, Arial)

## Alternatives to RTF

If RTF doesn't meet your needs:

### DOCX
- Better Word compatibility
- More features preserved
- Larger files
- (May be available in future updates)

### Plain Text
- Maximum compatibility
- No formatting
- Smallest files

### PDF
- For final output
- Not editable
- Exact appearance
