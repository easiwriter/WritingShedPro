# Prose Mode Overview

Prose projects are the most flexible project type in Writing Shed Pro. They're designed for essays, articles, blog posts, technical documentation, and any writing that doesn't require the specialized tools of Poetry, Fiction, or Drama projects.

## When to Use Prose Projects

Choose a Prose project when writing:
- Essays and academic papers
- Blog posts and articles
- Personal journals and diaries
- Technical documentation
- Business documents
- Any general-purpose writing

## Prose Project Structure

When you create a Prose project, you get these folders:

| Folder | Purpose |
|--------|---------|
| **Prose** | Your main writing area - all files live here |
| **Sections** | Optional organizational divisions |
| **Trash** | Deleted files (recoverable until emptied) |

### The Prose Folder
Unlike Fiction projects (which have separate Draft/Ready folders), Prose projects use a single **Prose** folder with workflow status to track each file's progress.

## Workflow Status

Every file has a workflow status:

| Status | Meaning |
|--------|---------|
| **Draft** | Work in progress |
| **Ready** | Complete and ready for use/export |
| **Set Aside** | On hold or archived |
| **Published** | Final, published version |

### Filtering by Status
At the top of the file list, tap status tabs to filter:
- **All** - Show all files
- **Draft (n)** - Show only drafts
- **Ready (n)** - Show ready files
- etc.

### Changing Status
1. Tap **Edit** in the file list
2. Select one or more files
3. Tap **Change Status** in the toolbar
4. Choose the new status

## Sections

Sections let you organize files into logical groups within a Prose project.

### What Are Sections?
Sections are like chapters or parts—they group related files together:
- A user guide might have sections for "Getting Started", "Features", "Reference"
- An essay collection might have sections for themes or time periods
- A journal might have sections for different years

### Creating Sections
1. Navigate to the **Sections** folder
2. Tap **+** to add a new section
3. Enter a name and optional synopsis

### Assigning Files to Sections
1. In the Prose file list, tap **Edit**
2. Select files with **Ready** status
3. Tap **Add to Section** in the toolbar
4. Choose the destination section

### Collapsible Section View
When files are assigned to sections, the main file list groups them by section:
- Tap a section header to expand/collapse
- Use the expand/collapse button to show/hide all sections
- File count displayed in each section header

See [Working with Sections](52-working-with-sections.md) for detailed instructions.

## Key Features

### Flexible Organization
- No enforced structure—organize however works for you
- Files can be ordered manually or sorted alphabetically
- Optional section grouping for larger projects

### Full Text Formatting
- All text styles (headings, body, captions, etc.)
- Character formatting (bold, italic, underline)
- Images with captions
- Footnotes and comments

### Import and Export
- Import Word (.docx) and Markdown (.md) documents
- Export to PDF, RTF, Word, HTML, or Markdown
- Batch export multiple files at once

### Search and Replace
- Search across all files in the project
- Find and replace with preview
- Regular expression support

| Script formatting | | | | ✓ |
| Workflow status | ✓ | ✓ | ✓ | ✓ |

## Best Practices

### Start Writing First
Don't worry about organization initially. Create files, write content, then organize later.

### Use Sections for Larger Projects
If your project has 10+ files, consider grouping them into sections.

### Leverage Workflow Status
Use Draft → Ready → Published to track progress. Filter by status to focus on current work.

### Export Regularly
Export finished work to PDF or other formats for backup and sharing.
