# Working with Sections

Sections help you organize files in Prose projects into logical groups. This guide covers creating, managing, and using sections effectively.

## Understanding Sections

Sections are organizational containers within a Prose project:
- Each section can hold multiple files
- Files can be assigned to one section (or none)
- Sections appear in the main file list as collapsible groups

### Examples of Section Use
- **User Guide**: "Introduction", "Features", "Reference", "Appendix"
- **Essay Collection**: "Personal", "Academic", "Published"
- **Blog Archive**: "2024", "2025", "Drafts"
- **Research Project**: "Literature Review", "Methods", "Results", "Discussion"

## Creating Sections

### From the Sections Folder
1. Navigate to your Prose project
2. Tap the **Sections** folder
3. Tap **+** (or Add Section)
4. Enter a section name
5. Optionally add a synopsis
6. Tap **Create**

### Section Properties
- **Name**: The section title (required)
- **Synopsis**: Brief description (optional)
- **Order**: Sections can be reordered by dragging

## Managing Sections

### Viewing Sections
Open the **Sections** folder to see all sections with:
- Section name
- File count
- Synopsis preview

### Reordering Sections
1. In the Sections folder, tap **Edit**
2. Drag sections using the grip handle
3. Tap **Done**

The order affects how sections appear in the main file list.

### Renaming a Section
1. Tap the section row's menu (⋯)
2. Select **Rename**
3. Enter the new name
4. Tap **Save**

### Deleting a Section
1. Tap the section row's menu (⋯)
2. Select **Delete**
3. Confirm deletion

**Note**: Deleting a section unassigns its files (moves them to "Unassigned") but does not delete the files themselves.

## Assigning Files to Sections

### From the Main File List
1. In the Prose folder, tap **Edit**
2. Select one or more files (must have **Ready** status)
3. Tap **Add to Section** in the bottom toolbar
4. Choose the destination section
5. Files are moved to that section

### Why Ready Status Required?
Only files marked as "Ready" can be assigned to sections. This encourages completing drafts before organizing them into the final structure.

### Changing a File's Section
To move a file to a different section:
1. Select the file in Edit mode
2. Tap **Add to Section**
3. Choose the new section

### Removing from a Section
To unassign a file from its section:
1. Select the file in Edit mode
2. Tap **Add to Section**
3. Choose **None** or **Unassigned**

## The Collapsible Section View

When files are assigned to sections, the main file list displays them grouped:

### Section Headers
Each section shows:
- Disclosure triangle (▶/▼)
- Folder icon
- Section name
- File count in parentheses

### Expanding and Collapsing
- **Tap a section header** to expand or collapse it
- **Expand/Collapse All**: Use the toolbar button to toggle all sections

### Unassigned Section
Files not assigned to any section appear in an "Unassigned" group at the bottom of the list.

### When Sections Appear
The collapsible section view only appears when:
- Multiple sections exist with assigned files
- You're viewing the main Prose file list (not a specific section)

## Viewing Section Contents

### From the Main List
Expand a section header to see its files inline.

### From the Sections Folder
1. Open the **Sections** folder
2. Tap a section name
3. View only that section's files

This dedicated view allows:
- Reordering files within the section
- Focused editing without other sections visible

## Reordering Files Within a Section

When viewing a specific section's files:
1. Drag files to reorder them
2. Order is preserved for export

The order matters for:
- Export order when generating combined documents
- Reading sequence

## Tips for Using Sections

### Plan Your Structure
Before creating sections, sketch out your project's organization. It's easier to assign files to a planned structure than to reorganize later.

### Use Descriptive Names
Section names should clearly indicate content: "Chapter 1: Introduction" rather than just "Chapter 1".

### Keep Sections Manageable
If a section has 20+ files, consider splitting it into subsections or rethinking your organization.

### Review Unassigned Files
Periodically check the Unassigned group—these files may need to be organized or deleted.

### Export by Section
When exporting, you can choose to export individual sections as separate documents.
