# Scene Organization

Scenes are the fundamental building blocks of fiction in Writing Shed Pro. This guide covers creating, organizing, and linking scenes effectively.

## Understanding Scenes

A scene is a continuous unit of action that:
- Happens in one place and time
- Has a purpose (advance plot, reveal character, etc.)
- Ends with a change or outcome

## Creating Scenes

### In the Draft Folder
1. Open the **Draft** folder
2. Tap **+**
3. Enter a scene title
4. Tap **Create**

The scene opens in the editor.

### Scene Titles
Use titles that help you identify scenes:
- "Opening - Jake's apartment" (descriptive)
- "Jake meets Sarah" (action-based)
- "1.1" (numerical, if you prefer)

You can always rename later.

## Scene Status

Scenes move through workflow folders:

| Folder | Status | Meaning |
|--------|--------|---------|
| Draft | Work in progress | Still being written/revised |
| Ready | Complete | Polished and final |
| Set Aside | On hold | Not currently working on |
| Trash | Deleted | Can be restored |

### Moving Scenes
1. Long-press the scene
2. Select **Move to...**
3. Choose the destination folder

## Linking Scenes to Plot Elements

Connect scenes to your story structure:

### From the Scene
1. Open the scene
2. Access scene details
3. Tap **Link to Plot Element**
4. Select the relevant plot element(s)

### From the Plot Element
1. Open a plot element
2. Tap **Create Scene**
3. A new scene is created and linked

### Why Link?
- Track story structure coverage
- Ensure all plot points have scenes
- Navigate between related content
- Visualize your story's shape

## Scene Details

Each scene can store metadata:

### Basic Info
- Title
- Status (Draft/Ready/etc.)
- Word count
- Creation date

### Story Connections
- Linked plot elements
- Associated characters
- Location

### Notes
- Scene summary
- Purpose/goal
- Revision notes

## Viewing Scenes

### In Folder Lists
- See title and preview
- Word count displayed
- Status indicated by folder

### Scene Detail View
- Full scene content
- All metadata
- Linked elements

## Reordering Scenes

### Within a Folder
1. Tap **Edit**
2. Drag scenes to new positions
3. Tap **Done**

### In Chapters
Scene order within chapters determines manuscript order. See [Chapter Management](02-chapter-management.md).

## Finding Scenes

### Browse by Folder
- Draft, Ready, Set Aside contain all scenes

### Search
- Use project search to find scenes by title or content

### By Plot Element
- Open a plot element to see linked scenes

### By Character/Location
- Open a character or location to see associated scenes

## Scene Best Practices

### Write First, Organize Later
Don't over-organize while drafting. Write scenes, then sort them into chapters.

### Use Status Meaningfully
- Draft = still working
- Ready = done (for now)
- Set Aside = maybe later

### Keep Scenes Focused
Each scene should have one primary purpose. If a scene does too much, consider splitting.

### Track Progress
Move scenes through the workflow as you complete them. It's motivating to see Ready fill up.

## Scenes and Plot

### Plotters
- Create plot elements first
- Generate scenes from plot elements
- Write to fill the structure

### Pantsers
- Write scenes as inspiration strikes
- Create plot elements retrospectively
- Link to discover your structure

### Plantsers
- Create loose plot elements
- Write scenes freely
- Adjust structure as you go

## Troubleshooting

### Can't Find a Scene
- Check all folders (Draft, Ready, Set Aside, Trash)
- Use search
- Check chapter contents

### Scene in Wrong Folder
- Long-press and select Move to...
- Or drag and drop

### Lost Scene Content
- Check version history
- Content auto-saves frequently
- Look in Trash if deleted
