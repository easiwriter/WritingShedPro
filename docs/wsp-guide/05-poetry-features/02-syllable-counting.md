# Syllable Counting

Syllable counting is essential for many poetry forms. Writing Shed Pro provides automatic syllable counting to help you maintain proper meter and form requirements.

## Understanding Syllable Counts

Many poetry forms require specific syllable counts:
- **Haiku**: 5-7-5 syllables
- **Tanka**: 5-7-5-7-7 syllables
- **Limerick**: Variable, roughly 8-8-5-5-8

Writing Shed Pro counts syllables automatically, displaying the count for each line.

## Viewing Syllable Counts

When editing a poem with a syllable-based form:

1. Syllable counts appear at the right edge of each line
2. Counts update as you type
3. Compare against your form's requirements

### Visual Indicators
- Numbers show the syllable count
- Colors may indicate match/mismatch with form requirements
- Form reference panel shows expected counts

## How Syllable Counting Works

Writing Shed Pro uses a sophisticated syllable counting algorithm:

### CMU Pronouncing Dictionary
- Industry-standard pronunciation database
- Covers most English words
- Provides accurate syllable counts for known words

### Fallback Algorithm
For words not in the dictionary:
- Estimates based on vowel patterns
- Handles most cases well
- May vary from your intended pronunciation

## Accuracy Considerations

Syllable counting is an estimate, not absolute truth:

### Variables in English
- Regional pronunciation differs
- Poetic license allows variation
- Some words have multiple valid pronunciations

### Examples of Variation
- "Fire": 1 or 2 syllables?
- "Every": 2 or 3 syllables?
- "Comfortable": 3 or 4 syllables?

### Your Ear is Final
The count is a guide. If you hear 3 syllables, use 3—regardless of what the tool says.

## Syllable Counting Tips

### Trust but Verify
Use the count as a starting point, then read aloud to confirm.

### Watch for Problem Words
Learn which words the algorithm misses in your vocabulary.

### Consider Elision
In poetry, syllables can be elided (combined):
- "O'er" for "over"
- "E'en" for "even"
- Write as you intend to read

### Compound Words
The algorithm handles most compounds, but check unusual ones.

## Working with Syllable Counts

### Adjusting Line Length
If a line is too long:
- Find a shorter synonym
- Restructure the phrase
- Consider elision

If a line is too short:
- Add modifiers
- Choose longer synonyms
- Expand the imagery

### Maintaining Form
For strict forms like haiku:
1. Write your thought
2. Check the count
3. Adjust word choices
4. Verify by reading aloud

### Breaking Form
Sometimes a line needs an extra syllable for the right word. Many poets prioritize meaning over strict count. Know the rules, then decide when to break them.

## Syllables and Meter

Syllable count differs from meter:
- **Syllables**: How many beats
- **Meter**: Which beats are stressed

For metered verse, see [Verse Highlighting](04-verse-highlighting.md) for stress pattern analysis.

### Example
"To be or not to be" has 6 syllables with alternating stress (iambic trimeter):
```
to BE or NOT to BE
˘  ´  ˘  ´   ˘  ´
```

## Disabling Syllable Counts

If you find the counts distracting:
1. Toggle off syllable display in poem settings
2. Re-enable when needed for checking

The feature is there to help—use it when helpful, hide it when not.
