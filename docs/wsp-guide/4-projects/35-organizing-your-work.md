# Organizing Your Work

A well-organized project makes writing easier and more productive. This guide focuses on **organization strategy**: workflow status, ordering, and manuscript assembly decisions.

For step-by-step actions (creating, renaming, deleting, restoring, and detailed list operations), see [Folders and Files](34-folders-and-files.md).

## Workflow Status Lifecycle

Writing Shed Pro uses file workflow statuses to support a natural writing lifecycle:

```text
Draft → Ready → Published
  ↓
Set Aside
```

Deleted items go to the Trash folder.

### Draft Status

Where new work begins. Use Draft for:

- First drafts
- Work in progress
- Pieces that need revision

### Ready Status

Use Ready when a file is polished and complete. Ready signals:

- No more major edits needed
- Ready for submission or publication
- Your best, finished work

### Set Aside Status

For work you're not actively pursuing:

- Ideas that aren't working yet
- Seasonal pieces (waiting for the right time)
- Experiments you might return to

### Published Status

Published is usually set automatically when a submission is accepted.

### Trash

Deleted items land here. You can:

- Restore accidentally deleted work
- Review before permanent deletion
- Empty periodically to clean up

## Sorting and Ordering

Control how files appear in lists:

### Sort Options

- **Name**: Alphabetical (A-Z)
- **Date Created**: When files were made
- **Date Modified**: When files were last edited
- **User's Order**: Your custom arrangement

### Custom Ordering Notes

- Use **User's Order** when sequence matters (submissions, reading flow, revision passes)
- Keep one stable ordering strategy per folder to avoid accidental reshuffling
- Custom order is saved and syncs across devices

For exact tap-by-tap sorting and drag-reorder steps, see [Folders and Files](34-folders-and-files.md).

## Project Body Containers and Body Matter

Writing Shed Pro uses project-specific **body containers** to group content for manuscript assembly. Poetry Collections are one example, not the only one.

### Body Matter Units by Project

- **Prose**: Sections
- **Poetry**: Collections
- **Fiction (Novel)**: Chapters
- **Fiction (Short Fiction)**: Scenes (directly ordered)
- **Fiction (Verse Novel)**: Books
- **Drama**: Acts

These units are added to **Manuscript → Body Matter** and reordered. During export, body matter is assembled in that order.

### Common Uses

- Group related pieces into coherent units
- Build a deliberate reading order
- Organize long projects into manageable structure
- Control manuscript assembly order for export and print

See [Manuscript Structure](36-manuscript-structure.md) for full assembly behavior across project types, and [Poetry Collections](../11-advanced-features/104-collections.md) for Poetry-specific details.

## Searching

Find files quickly with search:

### Project Search

1. From the project view, tap the search icon
2. Type your search term
3. Results show matching files

### Within a Folder

Search scope is limited to the current folder.

### Search Options

- Search by file name
- Search within file content
- Case-insensitive by default

For advanced find/replace workflows inside files, see [Search and Replace](../11-advanced-features/101-search-and-replace.md).

## Tags and Metadata

While Writing Shed Pro doesn't have explicit tags, you can use:

### Naming Conventions

Add prefixes or suffixes to file names:

- `[WIP] Poem Title` for work in progress
- `Poem Title - Sonnet` for form
- `Poem Title (Contest)` for destination

### Details Field

Use the file details field for notes, tags, or metadata.

## Workflow Examples

### Poetry Workflow

1. New poem → Draft
2. Revise and polish → keep status as Draft while revising
3. Complete → change status to Ready
4. Create Collection for submission
5. Submit → Track in Submissions
6. Accepted → status becomes Published

### Novel Workflow

1. Create scenes with Draft status
2. Link to plot elements
3. Organize into chapters
4. Change completed scenes/chapters to Ready
5. Assemble full manuscript for export

### General Writing Workflow

1. Start in Draft
2. Change to Ready when done
3. Export or print as needed

## Cleanup and Maintenance

Keep your project healthy:

### Regular Tasks

- Change finished work to Ready
- Change paused work to Set Aside
- Empty Trash monthly
- Review body containers for relevance

### Spring Cleaning

- Delete truly obsolete files
- Consolidate similar folders
- Update file names for clarity
- Archive completed projects

### Before Submitting

- Ensure work is set to Ready
- Double-check formatting
- Review in pagination view
- Export and proof
