# Comments

Comments let you add notes, feedback, and reminders without modifying your text. They're perfect for revision notes, editor feedback, and collaborative review.

## Understanding Comments

Comments appear as small indicators in your text:
- A speech bubble icon marks the comment location
- Tap to reveal the full comment content
- Comments don't print or export (by default)

## Adding a Comment

1. Place cursor where you want the comment
2. Tap the **⊕** (Insert) button in the toolbar
3. Select **Comment**
4. Type your comment text
5. Tap **Save**

A comment indicator appears at that position.

## Viewing Comments

### Tap to View
Tap any comment indicator to see:
- The comment text
- When it was created
- Options to edit or delete

### Comments Panel
For documents with many comments:
1. Open the Insert menu
2. Select **View Comments**
3. See all comments in a list

## Editing Comments

1. Tap the comment indicator
2. The comment popover appears
3. Tap to edit the text
4. Save your changes

## Deleting Comments

### From the Document
1. Tap the comment indicator
2. In the popover, tap **Delete**
3. Confirm if prompted

### From Comments Panel
1. Open **View Comments** from the Insert menu
2. Swipe left on the comment
3. Tap **Delete**

## Resolving Comments

When you've addressed a comment:
1. Tap the comment indicator
2. Tap **Resolve**

Resolved comments:
- Appear grayed out
- Remain in the document
- Can be filtered in the Comments panel
- Can be "unresolve" if needed

## Comment Workflow

### For Self-Review
Use comments to mark:
- Sections needing revision
- Research to add later
- Questions to consider
- Alternative phrasings

### For Feedback
Share documents with editors or beta readers who can:
- Add their comments
- Suggest changes
- Ask questions

### For Revision
Work through comments systematically:
1. Open Comments panel
2. Address each comment
3. Resolve when done
4. Delete or keep for reference

## Comments vs Footnotes

| Feature | Comments | Footnotes |
|---------|----------|-----------|
| Visible in export | No (by default) | Yes |
| For readers | No | Yes |
| Numbered | No | Yes |
| Purpose | Notes to self/collaborators | Reader information |

Use footnotes for reader-facing notes; use comments for behind-the-scenes notes.

## Comment Best Practices

### Be Specific
- Reference the exact issue
- Explain what needs attention
- Suggest solutions when possible

### Stay Organized
- Resolve comments as you address them
- Delete unnecessary comments
- Review before final export

### Use Consistently
- Develop a personal comment system
- Example: [TODO], [CHECK], [REVISE]
- Makes filtering easier

## Comments in Different Contexts

### Poetry
- Note potential word alternatives
- Mark rhythm problems
- Track revision history

### Fiction
- Scene notes
- Character consistency checks
- Plot hole reminders

### Academic
- Citation reminders
- Fact-check notes
- Argument strengthening

## Platform Differences

### iOS
- Comment popover from bottom
- Full-screen on iPhone
- Popover on iPad

### Mac
- Comment popover anchored to indicator
- Click outside to dismiss
- Keyboard navigation supported

## Troubleshooting

### Comment Not Visible
- Zoom in to see small indicators
- Check if comments are filtered
- Ensure comment was saved

### Too Many Comments
- Use Resolve to hide addressed ones
- Filter in Comments panel
- Delete unnecessary comments

### Comments in Export
- By default, comments don't export
- Check export settings if you want them included
- Consider converting to footnotes if readers should see them
