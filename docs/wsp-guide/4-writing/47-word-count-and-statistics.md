# Word Count and Statistics

Tracking your writing progress is motivating and practical. Writing Shed Pro provides detailed statistics at multiple levels.

## Detailed Statistics

For detailed counts at the file level:

1. Open the file
2. Open the file list and tap the file's **⋯** button
3. View the Statistics section

### Available Statistics

| Statistic | Description |
|-----------|-------------|
| **Words** | Total word count |
| **Characters** | Total characters (with spaces) |
| **Lines** | Number of lines |

## Body Matter Word Counts

Body Matter totals now appear directly in manuscript navigation:

- The Body Matter folder row shows a total word count for Body Matter content
- Body Matter container rows (for example chapters, acts, scenes, sections, collections, and books) show per-item word counts
- Singular/plural formatting is automatic (for example, "1 word" vs "250 words")

This gives you quick progress visibility without opening each item.

## Project-Level Counts

For a broader project view:

1. Open project settings
2. Select **Statistics**
3. See totals across all files

### Project Statistics Include
- Total words in project
- Total files
- Words per folder
- Growth over time (if tracked)

## Selection Statistics

Get counts for selected text only:

1. Select the text you're interested in
2. The selection word count appears
3. Useful for checking section length

## Using Statistics Effectively

### For Motivation
- Track daily word counts
- Celebrate milestones
- Visualize progress

### For Editing
- Identify overly long sections
- Balance chapter lengths
- Check against requirements

### For Submission
- Verify contest word limits
- Match publication guidelines
- Accurate reporting

## Statistics Tips

### Word Count Accuracy
Writing Shed Pro counts words by:
- Separating on whitespace and punctuation
- Handling contractions as single words
- Including hyphenated words as single words

This matches most submission guidelines.

### When Counts Differ
Different tools may count slightly differently:
- Hyphenated words
- Numbers
- Contractions

For submissions, note "approximately X words" or use the publication's preferred counting method.

### Page Counts
Page estimates depend on:
- Page size settings
- Font size
- Margins
- Spacing

Use pagination view for accurate page counts.

## Exporting Statistics

When you need to report statistics:
- Copy from the Statistics view
- Include in document exports
- Reference in cover letters
