# Poetry Mode Overview

Poetry projects in Writing Shed Pro provide specialized tools for poets working in both traditional forms and free verse. This overview explains what's available and how to use these features.

## What Makes Poetry Mode Special

Poetry mode understands that poets have unique needs:
- **Structure matters**: Syllable counts, line breaks, stanza organization
- **Sound matters**: Rhyme schemes, stress patterns, meter
- **Form matters**: Templates for sonnets, haiku, villanelles, and more
- **Precision matters**: Every word counts

## Creating a Poetry Project

1. From the project list, tap **+**
2. Enter a project name
3. Select **Poetry** as the project type
4. Tap **Create**

## Poetry Project Structure

Poetry projects include specialized folders:

| Folder | Purpose |
|--------|---------|
| **Poems** | Your main writing area — all poems live here |
| **Manuscript** | Front Matter, Body Matter, and Back Matter for export |
| **Collections** | Poetry Collections — group related poems together |
| **Submissions** | Track where you've sent work |
| **Research** | Reference material |
| **Magazines** | Publication targets |
| **Competitions** | Contest targets |
| **Other** | Miscellaneous files |
| **Trash** | Deleted poems (restorable) |

## Creating a Poem

### With a Form Template
1. Open the **Poems** folder
2. Tap **+**
3. Enter a title
4. Select a poetry form from the dropdown
5. Tap **Create**

The poem opens with the form's structure as a guide.

### Free Verse
1. Open the **Poems** folder
2. Tap **+**
3. Enter a title
4. Select **Free Verse** or leave form blank
5. Tap **Create**

Start with a blank page.

## Available Poetry Forms

Writing Shed Pro includes templates for 30+ traditional forms:

### Short Forms
- **Haiku** (5-7-5 syllables)
- **Tanka** (5-7-5-7-7 syllables)
- **Senryū** (5-7-5 syllables, human nature focus)

### Sonnets
- **Shakespearean** (ABAB CDCD EFEF GG)
- **Petrarchan** (ABBAABBA CDECDE)
- **Spenserian** (ABAB BCBC CDCD EE)

### Complex Forms
- **Villanelle** (19 lines, repeated lines)
- **Pantoum** (interlocking quatrains)
- **Sestina** (39 lines, word repetition)
- **Ghazal** (couplets with refrain)

### Other Forms
- **Limerick** (5 lines, AABBA)
- **Ballad** (quatrains, ABAB or ABCB)
- **Ode** (varied structure)
- **Free Verse** (no constraints)

You can also **create your own custom forms** — see [Forms and Templates](65-forms-and-templates.md) for details.

See [Forms and Templates](65-forms-and-templates.md) for the complete list.

## Poetry Tools in the Editor

When editing a poem, additional tools are available:

### Syllable Counter
Each line shows an estimated syllable count:
- Appears at the line's right edge
- Updates as you type
- Helps maintain syllabic forms

### Stress Pattern Display
For metered verse, view the stress pattern:
- Unstressed syllables: ˘
- Stressed syllables: ´
- Helps identify rhythm issues

### Mark Section (Insert Menu)
In poetry files, the **Insert** menu includes **Mark Section** for lines that are not part of the poem body.

Use this for content such as:
- Titles
- Epigraphs
- Dedications
- Signatures
- Stanza numbers

Purpose:
- Excludes marked lines from poetry analysis (syllables, stress, and related metrics)
- Visually distinguishes marked text in gray while drafting
- Keeps poem-body metrics focused on actual verse lines

How to use it:
1. Select text (or place the cursor on a line)
2. Open **Insert** → **Mark Section**
3. Choose **Add Marked Section**
4. Use **Unmark Selection** or **Clear All Marks** if needed

### Form Reference Panel
Access the rules for your selected form:
- Tap the **Form Info** button
- See line counts, rhyme schemes, other requirements
- Keep visible while writing

## Working with Rhyme

### Rhyme Scheme Display
Some forms show the expected rhyme scheme:
- Letters indicate rhyming lines (A, B, C, etc.)
- Helps you track the pattern

### Rhyme Suggestions (if available)
When seeking rhymes:
- Highlight a word
- Access rhyme tools
- See suggested rhyming words

See [Rhyme Tools](63-rhyme-tools.md) for details.

## Poetry Workflow

### Drafting
1. Choose a form (or free verse)
2. Use the template as a guide
3. Write without worrying about perfection
4. Check metrics as you go

### Revising
1. Review syllable counts
2. Check stress patterns
3. Verify rhyme scheme
4. Read aloud (essential!)

### Polishing
1. Change status to **Ready** when satisfied
2. Create Poetry Collections for related poems
3. Add collections to manuscript body matter for export
4. Submit to publications

## Poetry Collections

Poetry Collections are first-class entities in Poetry projects. Each collection has its own name, synopsis, and list of linked poems.

### Creating a Collection
1. Open the **Collections** folder
2. Tap **+**
3. Enter a name and optional synopsis
4. Tap **Create**

### Adding Poems
1. Navigate to poems in the Poems folder
2. Select one or more poems
3. Choose **Add to Collection...**
4. Select the target collection

### Body Matter Integration
Collections can be included in your manuscript's body matter:
1. Open the **Manuscript** folder → **Body Matter**
2. Add collections (and individual poems) to body matter
3. Reorder as needed
4. Collections are assembled in order during PDF/manuscript export

See [Poetry Collections](../11-advanced-features/104-collections.md) for more details.

## Tips for Poetry Mode

### Use Forms as Guides
Templates help but don't constrain. Break the rules when the poem demands it.

### Trust the Metrics
Syllable counts are estimates—English pronunciation varies. Your ear is the final judge.

### Read Aloud
No tool replaces hearing your poem. Read it aloud during revision.

### Organize by Theme
Use collections to group poems:
- By season or period
- By subject
- By form
- By submission target
