Tutorial: Assembling a Poetry Chapbook

This tutorial takes you through creating a chapbook-ready poetry manuscript in Writing Shed Pro — from organizing poems into collections to assembling front matter, body matter, and exporting a polished PDF.

Time: 30–40 minutes
Project Type: Poetry
Difficulty: Intermediate
Prerequisites: A Poetry project with at least 6–8 poems written

What You'll Learn

  • Creating and managing Poetry Collections
  • Adding poems to collections
  • Using Body Matter to assemble a manuscript
  • Setting up front matter (title page, copyright, dedication)
  • Reordering body matter items
  • Exporting to PDF

Step 1: Plan Your Chapbook

A chapbook is typically 20–40 pages of thematically linked poems. Before using the tools, decide:

  • Title: What will the chapbook be called?
  • Sections: Will you group poems by theme, chronology, or mood?
  • Order: Which poem opens? Which closes?

For this tutorial, we'll create a chapbook called "Seasons Turning" with two sections: "Spring/Summer" and "Autumn/Winter".

Step 2: Create Poetry Collections

Collections are how you group poems in Writing Shed Pro. Each section of your chapbook becomes a collection.

Create the First Collection

  1. Open the Collections folder
  2. Tap +
  3. Name it "Spring/Summer"
  4. Add a synopsis: "Poems of growth, warmth, and long days"
  5. Tap Create

Create the Second Collection

  1. Tap + again
  2. Name it "Autumn/Winter"
  3. Add a synopsis: "Poems of harvest, cold, and reflection"
  4. Tap Create

You now have two collections in the Collections folder.

Step 3: Add Poems to Collections

From the Poems Folder

  1. Open the Poems folder
  2. Tap Edit in the toolbar
  3. Select the poems for "Spring/Summer" (tap each one)
  4. Tap Add to Collection in the toolbar
  5. Select "Spring/Summer"
  6. Tap Done

Repeat for the "Autumn/Winter" poems.

Verify Your Collections

Open each collection to see its contents. The poems appear in the order you added them.

Remember: Adding a poem to a collection doesn't move it. The poem stays in the Poems folder — the collection is a virtual grouping. A poem can belong to multiple collections.

Step 4: Reorder Poems Within Collections

The order of poems in a collection matters — it's the reading order in your chapbook.

  1. Open the "Spring/Summer" collection
  2. Tap Edit
  3. Drag poems into your preferred order using the grip handles
  4. Tap Done

Think about flow: - Start strong with an accessible, inviting poem - Build emotional intensity through the middle - End with your strongest or most resonant piece

Repeat for the "Autumn/Winter" collection.

Step 5: Add Collections to Body Matter

Now assemble the manuscript. Body Matter is where you define what appears in the final document and in what order.

Open Body Matter

  1. Open the Manuscript folder
  2. Open Body Matter

Add Your Collections

  1. Tap + (or Add to Body Matter)
  2. You'll see your collections listed
  3. Add "Spring/Summer" first
  4. Add "Autumn/Winter" second

The Body Matter view now shows both collections. Each collection expands to show its poems underneath.

Reorder Body Matter

If you need to change the order: 1. Tap Edit in the Body Matter view 2. Drag collections (or individual poems) to reorder 3. Tap Done

Add Individual Poems (Optional)

If you have poems that don't belong to a collection but should appear in the chapbook: 1. Tap + in Body Matter 2. Select individual poems to add 3. Position them where you want (between collections, at the start, or at the end)

Step 6: Set Up Front Matter

A chapbook needs at minimum a title page. Professional submissions often include copyright and dedication pages too.

Title Page

  1. Open Manuscript → Front Matter
  2. Tap Title Page
  3. Type your chapbook title: Seasons Turning
  4. Add your author name
  5. Optionally add a subtitle or press/publisher name
  6. Format as desired (centered, larger font for the title)

Copyright Page

  1. Tap Copyright in Front Matter
  2. Add your copyright notice: © 2026 [Your Name] All rights reserved.
  3. Add any acknowledgments for previously published poems

Dedication

  1. Tap Dedication in Front Matter
  2. Add your dedication text (keep it brief)

Tip: You don't need to use all front matter files. Only the ones you add content to will appear in the export.

Step 7: Preview the Manuscript

Before exporting, preview how the chapbook will look:

  1. Go to Export Options (from the project menu or toolbar)
  2. Tap Preview
  3. Page through the preview to check:
  4. Title page layout
  5. Poem ordering
  6. Page breaks between poems
  7. Overall formatting

Step 8: Adjust Page Setup (Optional)

If you want chapbook-sized pages:

  1. Open Page Setup (from the project settings)
  2. Common chapbook sizes:
  3. Digest: 5.5" × 8.5" (half letter)
  4. A5: 148mm × 210mm (half A4)
  5. Trade: 6" × 9"
  6. Adjust margins — chapbooks typically use generous margins
  7. Set headers/footers as desired

Step 9: Export to PDF

  1. Open Export Options
  2. Select PDF
  3. Choose your settings:
  4. Include Table of Contents: Optional for chapbooks
  5. Page numbers: Usually yes
  6. Start new page for each poem: Recommended
  7. Tap Export
  8. Choose where to save the file

Your chapbook is now a professional PDF ready for submission or printing.

What You've Learned

  • Creating Poetry Collections to group thematically related poems
  • Adding poems to collections without moving or duplicating them
  • Using Body Matter to define manuscript reading order
  • Setting up front matter pages (title, copyright, dedication)
  • Reordering body matter items
  • Exporting the assembled manuscript to PDF

Tips for Real Chapbooks

  • Opening poem: Choose something accessible that hooks the reader
  • Closing poem: End with your strongest, most resonant piece
  • Section breaks: Use collections to create natural breathing points
  • Previously published: Note which poems appeared elsewhere (copyright page)
  • Page breaks: Each poem typically starts on a new page
