Submission Tracking

Writing Shed Pro helps poets and fiction writers track where they've submitted their work. Know what's pending, accepted, or rejected at a glance.

Understanding Submissions

The submission system tracks: - Publications: Magazines, journals, competitions - Submissions: What you sent, when, and current status - Submitted Files: Which specific file versions you sent

Setting Up Publications

Before tracking submissions, define your target publications:

Creating a Publication

  1. Open the Publications folder
  2. Tap +
  3. Enter publication details:
  4. Name (e.g., "Poetry Magazine")
  5. Type (Magazine or Competition)
  6. URL (optional)
  7. Notes (optional)
  8. Tap Create

Publication Types

  • Magazine: Journals, literary magazines, online publications
  • Competition: Contests with deadlines and prizes

Organizing Publications

  • Create entries for places you submit to regularly
  • Add notes about guidelines, preferences, or past interactions
  • Update URLs if publications change

Creating Submissions

When you send work out:

From a Collection

The recommended workflow: 1. Create a Collection with the files to submit 2. Open the Collection 3. Tap Submit to Publication 4. Select the publication 5. Confirm submission details 6. The submission is recorded

Direct Submission

  1. Open the Submissions folder
  2. Tap +
  3. Select the publication
  4. Choose files to include
  5. Set submission date
  6. Save

What Gets Recorded

  • Which files (and which versions)
  • Submission date
  • Target publication
  • Initial status (Pending)

Submission Statuses

Track the lifecycle of each submission:

Status Meaning
Pending Submitted, awaiting response
Accepted Publication accepted the work
Rejected Publication declined
Withdrawn You withdrew the submission

Updating Status

  1. Open the submission
  2. Change the status
  3. Add notes if desired (acceptance details, feedback)
  4. Save

Viewing Submissions

Submissions Folder

All submissions appear here: - Grouped by status - Shows publication name - Shows submission date - Shows file count

By Publication

Open a publication to see: - All submissions to that publication - History of your relationship - Acceptance rate

By File

Open a file's details to see: - Where it's been submitted - Current status of each submission - Submission history

Simultaneous Submissions

Many writers submit the same work to multiple publications: 1. Submit to Publication A 2. Submit same file to Publication B 3. Both submissions track independently 4. When one accepts, update statuses appropriately

Managing Simultaneous Submissions

  • Check publication policies (some prohibit simultaneous submissions)
  • Keep track to avoid awkward situations
  • Withdraw from others promptly upon acceptance

Version Tracking

Submissions record the exact version you sent: - If you edit the file later, the submission still references the original version - You can see exactly what was submitted - Helpful if an editor references specific content

Workflow Tips

Before Submitting

  1. Change files to Ready status
  2. Create a Collection for the submission package
  3. Proofread thoroughly
  4. Check submission guidelines

After Submitting

  1. Record the submission immediately
  2. Note any confirmation number
  3. Set a reminder notification for expected response time
  4. Monitor pending submissions

Notification Reminders

Writing Shed Pro can send you notification reminders for submissions and publication deadlines.

Submission Reminders

Set a reminder to follow up on a pending submission: 1. Open the submission details 2. Tap Set Reminder 3. Choose a date and time 4. A system notification will alert you when the reminder fires

Deadline Reminders

Set a reminder for publication deadlines (magazines and competitions): 1. Open the publication details 2. Tap Set Deadline Reminder 3. Choose a date and time 4. You'll receive a notification before the deadline

Managing Reminders

  • Reminders appear as standard system notifications with alert and sound
  • You can cancel a reminder from the submission or publication detail view
  • The app will request notification permission the first time you set a reminder
  • Reminders are one-time notifications (they do not repeat)

Upon Response

  1. Update the status
  2. Add any feedback to notes
  3. If rejected, consider next submission target
  4. If accepted, celebrate!

Track Everything

  • Even quick online submissions
  • Even free publications
  • Build your submission history

Reports and Statistics

View your submission activity: - Total submissions - Pending vs. completed - Acceptance rate - Response times

Use this data to: - Identify responsive publications - See your progress - Plan future submissions

Troubleshooting

Forgot to Record a Submission

  • Create it manually
  • Set the date to when you actually submitted
  • It's never too late to track

Status Changed Externally

  • Update in Writing Shed Pro to keep records accurate
  • Add notes explaining the situation

Files Changed After Submission

  • The submission still references the original version
  • You can see what was actually sent
