Manuscript and Export (Poetry)

This guide covers how Writing Shed Pro assembles Poetry project content into a manuscript for export.

How Poetry Manuscripts Are Assembled

Poetry manuscripts use a flat assembly model:

  1. Front Matter is placed first (Title Page, Copyright, etc.)
  2. All poems are assembled in display order
  3. Back Matter is appended (Endnotes, Glossary, Bibliography, Index)

Poem Ordering

Poems appear in the manuscript in their display order — the order you see them in the file list. To change the order: 1. Tap Edit in the file list 2. Drag poems to reorder using the grip handles 3. Tap Done

The manuscript follows this order exactly.

What Gets Included

By default, all poems are included. You can exclude individual poems: 1. Open the poem's context menu 2. Toggle Include in Manuscript off 3. The poem stays in your project but is skipped during assembly

This is useful for unfinished work, experiments, or poems earmarked for a different collection.

Previewing the Manuscript

Before exporting: 1. Open the Manuscript view 2. Review the assembled content 3. Check that poems appear in the correct order 4. Verify formatting is preserved 5. Confirm no unwanted poems are included

Poetry Formatting in the Manuscript

Poetry formatting is preserved during manuscript assembly: - Line breaks are maintained exactly as written - Stanza breaks (blank lines between stanzas) are preserved - Indentation is carried through to the output - Character formatting (bold, italic) is retained

Poem Breaks

Control how poems are separated in the manuscript:

Break Style Appearance
Page Break Each poem starts on a new page
Section Mark Centered mark (e.g., * * *) between poems
Double Space Extra blank line between poems
None Poems flow together continuously

For most poetry collections, Page Break is the standard — each poem begins on its own page.

Poem Titles

You can control whether poem titles appear as headings in the manuscript: - Include File Titles: Shows each poem's title as a heading above it - Disable this if your poems have their own title lines in the content

This setting is in Export Options.

Export Formats

Poetry manuscripts can be exported in all available formats:

Format Best For
PDF Submissions, chapbooks, reading copies — preserves exact line placement
RTF Editor collaboration, Word-compatible
HTML Online publication, web journals
Markdown Plain text archives, version control

Why PDF Is Usually Best for Poetry

PDF preserves line breaks, spacing, and indentation exactly. Other formats may reflow text depending on the reader's settings, which can alter the visual layout of a poem.

Exporting

  1. Open the Manuscript view
  2. Tap the export/share button
  3. Choose your format
  4. Configure options (page setup, back matter toggles)
  5. Save or share

Collection Export

In addition to full manuscript export, you can export individual collections: 1. Open a Collection 2. Tap the export/share button 3. Only poems in that collection are included 4. Same format options apply

This is useful for: - Submitting a specific group of poems to a journal - Creating themed chapbooks - Sharing a curated selection with beta readers

Tips

One Poem Per Page

For submissions and chapbooks, use Page Break as the section break style. Most editors and publishers expect each poem to start on its own page.

Order Matters

Arrange your poems thoughtfully before exporting. The sequence of poems in a collection or manuscript is a creative decision — it shapes how readers experience your work.

Exclude Experiments

Use the Include in Manuscript toggle to keep exploratory drafts in your project without cluttering the export.

Check Line Breaks in PDF

Always preview the PDF to ensure long lines wrap as intended. Adjust page margins if lines are breaking awkwardly.
