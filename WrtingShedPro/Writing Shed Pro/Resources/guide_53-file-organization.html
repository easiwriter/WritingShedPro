File Organization in Prose Projects

This guide covers strategies for organizing files within Prose projects, from simple single-file documents to complex multi-file projects.

Organizing Strategies

Single-File Approach

For short documents (articles, essays, blog posts): - Create one file per document - Use workflow status to track progress - No sections needed

Multi-File Approach

For longer documents (user guides, book-length works): - Break content into logical files - Use sections to group related files - Order files within sections for export

Hybrid Approach

Mix both as needed: - Main content in organized sections - Supporting materials (notes, research) as standalone files

File Naming Conventions

Good file names help you navigate your project quickly.

Recommended Patterns

Numbered Prefix

01-introduction
02-getting-started
03-main-features
04-advanced-topics

Category Prefix

guide-installation
guide-features
ref-shortcuts
ref-faq

Date Prefix (for journals/logs)

2025-01-15-meeting-notes
2025-01-20-project-update

Naming Tips

  • Keep names concise but descriptive
  • Use lowercase with hyphens (avoids case-sensitivity issues)
  • Include numbers for ordering if sequence matters
  • Avoid special characters

Workflow Status Strategy

Use workflow status to track where each file is in your process:

The Standard Flow

Draft → Ready → Published
  1. Draft: Active writing/editing
  2. Ready: Complete, reviewed, ready for use
  3. Published: Final version, exported/published

Alternative Flows

For Ongoing Projects

Draft → Ready (loop back as needed)

For Review Process

Draft → Ready (for review) → Published (after approval)

Set Aside Status

Use "Set Aside" for: - Content you might use later - Alternate versions - Archived material

This keeps your active lists focused.

Using Filters Effectively

Focus on Current Work

Filter to Draft to see only work in progress.

Review Ready Files

Filter to Ready when preparing to: - Export documents - Assign files to sections - Do final review

Check Published

Filter to Published to see completed work.

View All

Switch to All for complete project overview.

Ordering Files

Manual Ordering (Within Sections)

When viewing a section's files: 1. Long-press a file to initiate drag 2. Drop in the desired position 3. Order is saved automatically

This order is used when exporting the section.

Alphabetical Ordering (Main List)

In the main Prose file list, files are sorted alphabetically by default. Use numbered prefixes in file names to control order.

The Trash Folder

Deleted files go to Trash rather than being permanently removed.

Recovering Files

  1. Open the Trash folder
  2. Find the file
  3. Tap menu (⋯) → Restore
  4. File returns to the Prose folder

Permanent Deletion

  1. In Trash, tap Edit
  2. Select files
  3. Tap Delete Forever

Warning: Permanent deletion cannot be undone.

Empty Trash

To delete all trashed files: 1. Open Trash 2. Tap Empty Trash 3. Confirm

File Details

View file information by tapping the menu (⋯) → Details:

Information Shown

  • Created: When the file was created
  • Modified: Last edit date/time
  • Word Count: Total words
  • Character Count: Total characters
  • Section: Which section (if any)
  • Status: Current workflow status

Import and Organization

When importing files: 1. Files are added to the Prose folder 2. Status defaults to Draft 3. Section is unassigned

Post-Import Steps

  1. Review imported content
  2. Rename if needed (menu → Rename)
  3. Change status when ready
  4. Assign to sections as appropriate

Export and Organization

File organization affects export:

Single File Export

Each file exports as a separate document.

Section Export

Export all files in a section as one combined document (in file order).

Project Export

Export the entire project (all files) as one document.

Tips for Large Projects

Break Files by Topic

One topic per file is easier to manage than monolithic documents.

Use Sections for Major Divisions

Sections should represent major divisions (parts, chapters, categories).

Regular Cleanup

Periodically review: - Move completed work to Published - Set aside inactive files - Delete outdated content

Consistent Naming

Establish naming conventions early and stick to them.

Use Synopses

Add synopses to sections to remember what each contains.
