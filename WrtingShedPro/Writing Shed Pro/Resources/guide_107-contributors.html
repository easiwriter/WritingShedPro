Contributors

The Contributors section is a back matter feature designed for magazine editors, anthology publishers, and anyone who needs to list the contributors to a publication with their biographical notes.

Overview

Contributors is a user-created list (unlike auto-generated back matter like Endnotes or Glossary). Each entry contains:

  • First Name — The contributor's given name
  • Surname — The contributor's family/last name
  • Biography — A biographical note about the contributor

The list is automatically sorted alphabetically by surname, then by first name.

Setting Up Contributors

Enable the Contributors File

  1. Open your project
  2. Navigate to Manuscript → Back Matter
  3. Open Back Matter Settings from the folder menu
  4. Enable Contributors
  5. A "Contributors" file will be created in the Back Matter folder

Adding a Contributor

  1. Open the Contributors file in Back Matter
  2. Tap the + button in the toolbar
  3. Fill in the contributor details:
  4. First Name: Enter the contributor's first name
  5. Surname: Enter the contributor's surname/last name
  6. Biography: Write a biographical note (can be multiple paragraphs)
  7. Tap Save

The new contributor appears in the list, automatically sorted by surname.

Editing a Contributor

  1. Tap on the contributor entry you want to edit
  2. The editor sheet opens with the existing details
  3. Make your changes
  4. Tap Save

Deleting a Contributor

You can delete contributors in two ways:

Swipe to Delete: 1. Swipe left on the contributor entry 2. Tap the Delete button

Context Menu: 1. Long-press on the contributor entry 2. Select Delete from the context menu 3. Confirm the deletion

Export Format

When you export your manuscript to PDF or print, the Contributors section appears in the back matter with this format:

CONTRIBUTORS

Jones, Sarah
Sarah Jones is a poet whose work has appeared in numerous
literary magazines. She lives in Portland, Oregon.

Smith, John
John Smith is the author of three novels and has won
the National Book Award for Fiction.

Contributors are sorted alphabetically by surname in the exported document.

Tips

Writing Effective Biographies

  • Keep biographies concise (2-4 sentences is typical)
  • Include relevant credentials or publications
  • Mention the contributor's location if appropriate
  • Use third person ("Sarah Jones is..." not "I am...")

Managing Many Contributors

For anthologies with many contributors: - Add contributors as you accept submissions - Use consistent formatting for all biographies - Review the full list before export to ensure alphabetical ordering looks correct
