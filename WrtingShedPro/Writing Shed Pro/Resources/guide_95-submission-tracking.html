Submission Tracking

Writing Shed Pro helps poets and fiction writers track where they've submitted their work. Know what's pending, accepted, or rejected at a glance.

Understanding Submissions

The submission system tracks:

  • Publications: Magazines, journals, competitions
  • Submissions: What you sent, when, and current status
  • Submitted Files: Which specific file versions you sent

Setting Up Publications

Before tracking submissions, define your target publications:

Creating a Publication

  • Open the Publications folder
  • Tap +
  • Enter publication details:

    • - Name (e.g., "Poetry Magazine")

    - Type (Magazine or Competition)

    - URL (optional)

    - Notes (optional)

  • Tap Create

    • Publication Types

    • Magazine: Journals, literary magazines, online publications
    • Competition: Contests with deadlines and prizes

    Organizing Publications

    • Create entries for places you submit to regularly
    • Add notes about guidelines, preferences, or past interactions
    • Update URLs if publications change

    Creating Submissions

    When you send work out:

    From a Collection

    The recommended workflow:

  • Create a Collection with the files to submit
  • Open the Collection
  • Tap Submit to Publication
  • Select the publication
  • Confirm submission details
  • The submission is recorded

    • Direct Submission

  • Open the Submissions folder
  • Tap +
  • Select the publication
  • Choose files to include
  • Set submission date
  • Save

    • What Gets Recorded

    • Which files (and which versions)
    • Submission date
    • Target publication
    • Initial status (Pending)

    Submission Statuses

    Track the lifecycle of each submission:

    StatusMeaning
    PendingSubmitted, awaiting response
    AcceptedPublication accepted the work
    RejectedPublication declined
    WithdrawnYou withdrew the submission

    Updating Status

  • Open the submission
  • Change the status
  • Add notes if desired (acceptance details, feedback)
  • Save

    • Viewing Submissions

    Submissions Folder

    All submissions appear here:

    • Grouped by status
    • Shows publication name
    • Shows submission date
    • Shows file count

    By Publication

    Open a publication to see:

    • All submissions to that publication
    • History of your relationship
    • Acceptance rate

    By File

    Open a file's details to see:

    • Where it's been submitted
    • Current status of each submission
    • Submission history

    Simultaneous Submissions

    Many writers submit the same work to multiple publications:

  • Submit to Publication A
  • Submit same file to Publication B
  • Both submissions track independently
  • When one accepts, update statuses appropriately

    • Managing Simultaneous Submissions

    • Check publication policies (some prohibit simultaneous submissions)
    • Keep track to avoid awkward situations
    • Withdraw from others promptly upon acceptance

    Version Tracking

    Submissions record the exact version you sent:

    • If you edit the file later, the submission still references the original version
    • You can see exactly what was submitted
    • Helpful if an editor references specific content

    Workflow Tips

    Before Submitting

  • Move files to Ready folder
  • Create a Collection for the submission package
  • Proofread thoroughly
  • Check submission guidelines

    • After Submitting

  • Record the submission immediately
  • Note any confirmation number
  • Set a reminder for response time (if guidelines specify)

    • Upon Response

  • Update the status
  • Add any feedback to notes
  • If rejected, consider next submission target
  • If accepted, celebrate!

    • Track Everything

    • Even quick online submissions
    • Even free publications
    • Build your submission history

    Reports and Statistics

    View your submission activity:

    • Total submissions
    • Pending vs. completed
    • Acceptance rate
    • Response times

    Use this data to:

    • Identify responsive publications
    • See your progress
    • Plan future submissions

    Troubleshooting

    Forgot to Record a Submission

    • Create it manually
    • Set the date to when you actually submitted
    • It's never too late to track

    Status Changed Externally

    • Update in Writing Shed Pro to keep records accurate
    • Add notes explaining the situation

    Files Changed After Submission

    • The submission still references the original version
    • You can see what was actually sent
