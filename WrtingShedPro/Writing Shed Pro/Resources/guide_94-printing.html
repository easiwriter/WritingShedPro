Printing

Writing Shed Pro supports printing on both iOS and Mac. Print directly to any available printer for physical copies of your work.

What You Can Print

Single Files

Print any individual text file.

Collections

Print all files in a collection as a single document.

Submissions

Print all files in a submission together.

Manuscripts (Fiction)

Print your assembled manuscript with chapters in order.

How to Print

From a File

  1. Open the file you want to print
  2. Tap the Share or Print button
  3. Select Print
  4. Configure print options
  5. Tap Print

From a Collection

  1. Open the collection
  2. Tap Print or access via Share menu
  3. All files print as one document
  4. Configure options and print

Print Options

Printer Selection

  • Choose from available printers
  • iOS: AirPrint-compatible printers
  • Mac: All system printers

Copies

Select how many copies to print.

Page Range

  • All pages
  • Specific page range

Paper Size

Match your page setup settings: - Letter (8.5 × 11 inches) - A4 (210 × 297 mm) - Other sizes as available

Orientation

  • Portrait (vertical)
  • Landscape (horizontal)

Duplex (if supported)

  • Single-sided
  • Double-sided

Print Preview

Always preview before printing:

On iOS

The print dialog shows a preview. Pinch to zoom and scroll through pages.

On Mac

Click the preview in the print dialog. Review all pages before printing.

What Gets Printed

Included

  • All text with formatting
  • Paragraph styles
  • Images
  • Footnotes in correct positions
  • Headers and footers (if configured)
  • Page numbers

Not Included

  • Comments (by default)
  • Writer's notes
  • Metadata

Page Setup for Printing

Before printing, ensure your page setup matches:

  1. Open Page Setup in project settings
  2. Set paper size to match your printer paper
  3. Configure margins
  4. Set headers/footers if wanted
  5. Check in Pagination View

See Page Setup for details.

Printing Tips

Proofread on Paper

Many writers catch errors on paper that they miss on screen. Print drafts for review.

Use Draft Mode

For quick reviews, consider: - Lower quality settings - Single-sided - Cheaper paper

Final Copies

For submissions or archiving: - High-quality settings - Good paper - Check for smudges or issues

Save Paper

  • Use both sides (duplex)
  • Print multiple pages per sheet if reading comfort allows
  • Print only necessary pages

Platform-Specific Notes

iOS Printing

  • Requires AirPrint-compatible printer
  • Printer must be on the same Wi-Fi network
  • Some office printers support AirPrint
  • Third-party apps can add non-AirPrint printer support

Mac Printing

  • All system printers available
  • USB and network printers
  • Full print dialog with more options
  • PDF saving option in print dialog

Troubleshooting Printing

Can't Find Printer

  • Check printer is on and connected
  • Verify Wi-Fi connection (iOS)
  • Try restarting printer
  • Check printer setup in system settings

Printing Looks Wrong

  • Check page setup matches paper
  • Review in Pagination View first
  • Verify printer settings (margins, scaling)

Pages Cut Off

  • Margins may be too small
  • Some printers have unprintable areas
  • Adjust page setup margins

Images Not Printing

  • Check printer has enough ink
  • Verify images appear in preview
  • Try printing a test page

Print Job Stuck

  • Cancel and retry
  • Restart printer
  • Check printer queue on your device

Alternatives to Printing

If direct printing isn't working: 1. Export as PDF 2. Print the PDF from any device/app 3. Use a different printer or print service
