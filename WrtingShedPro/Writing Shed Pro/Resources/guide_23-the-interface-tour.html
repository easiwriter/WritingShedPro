The Interface Tour

This guide walks you through Writing Shed Pro's interface, helping you understand where everything is and how to navigate efficiently.

Main Screen: Project List

When you launch Writing Shed Pro, you see the Project List. This is your home base.

Project List Elements

  • Navigation Bar: Shows "Projects" title and action buttons
  • Add Button (+): Create new projects
  • Sort Button: Change project ordering
  • Project Cards: Each project shows its name, type, and last modified date

Project Actions

  • Tap a project to open it
  • Swipe left to delete
  • Long-press for more options (rename, duplicate, details)

Inside a Project

Tapping a project opens its folder structure. The layout adapts to your device:

iPhone Layout

  • Single-column navigation: Tap folders to drill down
  • Back button: Return to previous level
  • Long-press back button: Jump directly to the project root

iPad and Mac Layout

  • Sidebar: Shows folder hierarchy
  • Content area: Shows selected folder's contents or file editor
  • Optional inspector: Shows details about selected items

The Toolbar

The toolbar appears at the top of most screens and provides context-specific actions.

Project View Toolbar

  • Back arrow: Return to project list
  • Project name: Tap to edit
  • Gear icon: Project settings
  • Question mark: Open user guide

Folder View Toolbar

  • Back arrow: Return to parent folder
  • Folder name: Current location
  • Add (+): Create files or subfolders
  • Edit: Enter edit mode for reordering and deletion
  • Sort: Change sort order

File Editor Toolbar

  • Back arrow: Return to folder
  • File name: Tap to rename
  • Formatting toolbar: Text styling options
  • More (...): Additional actions

The Formatting Toolbar

When editing text, a formatting toolbar appears above the keyboard:

Paragraph Style Picker

Tap ¶ to see available paragraph styles:

  • Body (default text)
  • Heading 1, 2, 3
  • Subheadline
  • Caption
  • Footnote
  • And more...

Tap a style to apply it to the current paragraph.

Insert Menu

Tap ⊕ to insert:

  • Image: Add a photo or illustration
  • Footnote: Create a numbered footnote
  • Comment: Add a revision note

The Text Selection Menu

When you select text by double-tapping or dragging, a menu appears:

  • Cut: Remove and copy to clipboard
  • Copy: Copy to clipboard
  • Paste: Insert from clipboard
  • Select All: Select entire document
  • Look Up: Dictionary and web search
  • Translate: Apple's translation
  • Edit Style: Open the style editor

Specialized Views

Poetry Projects

  • Form Reference Panel: Shows the rules for your selected poetry form
  • Metrics Display: Syllable counts and stress patterns per line

Fiction Projects

  • Plot Outline: Visual timeline of plot elements
  • Scene Detail: Edit scene content and metadata
  • Character/Location Lists: Manage story elements

Drama Projects

  • DML Editor: Write scripts in Drama Markup Language
  • Preview Mode: See formatted output (film or stage format)

Navigation Shortcuts

Long-Press Back Button

From any nested view, long-press the back button to see the navigation stack. Tap any level to jump directly there, or hold to return to the project root.

Keyboard Shortcuts (Mac and iPad with keyboard)

  • ⌘N: New file
  • ⌘F: Find in file
  • ⌘G: Find next
  • ⌘⇧G: Find previous
  • ⌘B: Bold
  • ⌘I: Italic
  • ⌘U: Underline

See Keyboard Shortcuts for the complete list.

Customizing the Interface

Appearance

Writing Shed Pro follows your system's appearance settings:

  • Light mode
  • Dark mode
  • Automatic (follows system)

Text Size

Text in the editor respects your system's Dynamic Type settings. Increase system text size in Settings → Accessibility → Display & Text Size for larger editor text.
