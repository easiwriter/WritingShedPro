PDF Export

PDF is the most reliable export format for sharing and submissions. The PDF looks identical on every device and platform.

Why PDF?

Advantages

  • Universal: Opens on any device
  • Fixed: Looks exactly as you designed it
  • Secure: Hard to accidentally edit
  • Professional: Industry standard for submissions

When to Use PDF

  • Submitting to magazines, agents, publishers
  • Sharing for review (where editing isn't needed)
  • Archiving finished work
  • Creating reading copies

Exporting to PDF

Single File

  1. Open the file you want to export
  2. Tap the Share or Export button
  3. Select Export as PDF
  4. Review settings if prompted
  5. Choose where to save or how to share

Multiple Files (Collection/Submission)

  1. Open the collection or submission
  2. Tap Export
  3. Select PDF
  4. Files combine into one PDF
  5. Save or share

Manuscript (Fiction)

  1. Assemble your manuscript
  2. Export as PDF
  3. All chapters included in order

PDF Settings

Page Setup

Before exporting, ensure your page setup is correct: - Paper size (Letter, A4, etc.) - Margins - Headers and footers - Orientation

These settings determine how the PDF appears.

Quality

  • Standard quality works for most uses
  • Higher quality for print-ready PDFs
  • Lower quality reduces file size

Page Range

  • All pages (default)
  • Specific pages if needed

What's Included in PDF

Always Included

  • All text with formatting
  • Paragraph styles
  • Images at current resolution
  • Footnotes in correct positions
  • Page numbers (if configured)
  • Headers/footers (if configured)

Hyperlinks

  • External links remain clickable
  • Internal links work within the PDF
  • Cross-file links point to correct pages

Not Included

  • Comments (by default)
  • Edit capability
  • Writer's notes

Previewing Before Export

Always preview before exporting:

  1. Switch to Pagination View
  2. Review each page
  3. Check:
  4. Page breaks
  5. Footnote placement
  6. Image positions
  7. Headers/footers
  8. Make adjustments if needed
  9. Then export

File Size Considerations

PDF size depends on: - Number of pages - Number and size of images - Embedded fonts

Reducing File Size

  • Optimize images before inserting
  • Use fewer high-resolution images
  • Choose "smaller file size" option if available

When Size Matters

  • Email attachments (often limited to 25MB)
  • Some submission systems have limits
  • Cloud storage usage

Sharing PDFs

After export, share via: - Email: Attach the PDF - AirDrop: Quick iOS/Mac sharing - Cloud Storage: Upload to iCloud, Dropbox, etc. - Files App: Save and access from other apps

PDF for Submissions

Standard Manuscript Requirements

Many submissions expect: - Standard fonts (Times New Roman, Courier) - Double spacing - 1-inch margins - Page numbers - Author name/title in header

Configure these in Page Setup and Stylesheet before exporting.

Check Guidelines

Always read submission guidelines. Some specify: - Maximum file size - Specific formatting - Cover letter requirements - Naming conventions

Troubleshooting PDF Export

PDF Looks Different Than Expected

  • Check Pagination View first
  • Verify Page Setup settings
  • Ensure fonts are available

Images Missing or Wrong Size

  • Check original image quality
  • Verify image scale settings
  • Try re-inserting the image

PDF Too Large

  • Reduce image count/size
  • Choose smaller export quality
  • Compress after export if needed

Links Not Working

  • Ensure links were created correctly
  • Test in the exported PDF
  • Some PDF viewers handle links differently
