Tips and Tricks

Power tips to get the most out of Writing Shed Pro.

Writing Tips

Write First, Format Later

Don't get distracted by fonts and styles while drafting. Get your ideas down first, then polish.

Use the Right Project Type

Choose Poetry, Fiction, or Drama when appropriate. The specialized tools are worth it.

Let Auto-Save Work

Stop hitting Cmd+S. Your work saves constantly. Trust the system.

Read Aloud

Even with syllable counting and stress analysis, nothing replaces reading your work aloud.

Organization Tips

Use Collections, Not Copies

Instead of duplicating files for different purposes, add them to multiple collections. One source of truth.

Move to Ready When Done

Moving files to Ready isn't just organization—it's a psychological commitment that the piece is finished.

Empty Trash Regularly

Old deleted files take up space and clutter your backups. Clean up monthly.

Use Subfolders Sparingly

Two or three levels deep is plenty. Too much nesting makes things hard to find.

Editing Tips

Use Find and Replace Carefully

Always preview before Replace All. It's faster to check twice than to undo a mess.

Master the Selection Menu

Double-tap for word, triple-tap for paragraph. The selection menu offers powerful options.

Learn Five Shortcuts

You don't need to learn them all. Start with: ⌘Z, ⌘B, ⌘I, ⌘F, and ⌘C/V. Add more as needed.

Comments for Future You

Leave comments on tricky passages: "Check this date" or "Consider cutting this scene."

Poetry Tips

Trust Your Ear

The syllable counter and stress analyzer are guides, not gods. If your ear says it works, it works.

Try Templates

Even if you write free verse, try a sonnet or villanelle sometime. Constraints spark creativity.

One Poem Per File

It's tempting to put all your haiku in one file, but individual files are easier to organize and submit.

Fiction Tips

Scenes Are Small

A scene should be one continuous action. If in doubt, make it smaller.

Link to Plot Elements

Connecting scenes to plot elements helps you see your story's structure. Do it even if you're a "pantser."

Use Character and Location Notes

You'll forget details six months into a novel. Record them now.

Don't Over-Plan

The tools for chapters and plot elements are there if you want them. You don't have to use everything.

Drama Tips

Learn Basic DML

Just the essentials: # for headings, > for action, character names in caps. That's 80% of what you need.

Check Both Formats

Toggle between Film and Stage output to see how your script adapts. It might reveal opportunities.

Read Scripts

Study professional scripts in your target format. Internalize the conventions.

Export Tips

Preview in Pagination View

Always check pagination before export. Catch issues early.

PDF for Submissions

Unless specifically asked for something else, PDF is the safest choice.

Match the Requirements

Read submission guidelines carefully. Format exactly as requested.

Sync Tips

Trust iCloud

Files sync automatically. No need to force anything.

Wait Before Switching Devices

If you've just made changes, wait a few seconds for sync before opening on another device.

Keep Backups

Export important finished work as PDFs. It's a good safety net.

Hidden Features

Long-Press Back Button

Jump directly to the project root from any nested view.

Pinch to Zoom

In the editor, pinch to zoom for comfortable reading or precise editing.

Shake to Undo

On iPhone, shake the device to trigger undo.

Three-Finger Swipe

Left for undo, right for redo. Works in most text areas.

Workflow Suggestions

Daily Writing

  1. Open project
  2. Create new file in Draft
  3. Write without editing
  4. Save (automatic)
  5. Come back tomorrow

Revision Session

  1. Open file from Draft
  2. Read through
  3. Use comments to mark issues
  4. Make changes
  5. When satisfied, move to Ready

Submission Day

  1. Review files in Ready
  2. Create Collection for submission
  3. Export or submit
  4. Record the submission
  5. Track status
