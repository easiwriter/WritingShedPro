Tutorial: Submitting Your Work

This tutorial covers the complete submission workflow in Writing Shed Pro — from setting up publications to tracking responses. You'll learn to manage submissions, set notification reminders, and handle simultaneous submissions.

Time: 20–30 minutes
Project Type: Poetry (works similarly for Fiction and Drama)
Difficulty: Intermediate
Prerequisites: A project with finished work ready to submit

What You'll Learn

  • Setting up publications (magazines and competitions)
  • Creating a submission from a Poetry Collection
  • Tracking submission status (Pending → Accepted/Rejected)
  • Setting notification reminders for follow-ups and deadlines
  • Managing simultaneous submissions
  • Keeping a submission history

Step 1: Set Up Your Target Publications

Before submitting, define where you'll send your work.

Create a Magazine

  1. Open the Submissions folder (or navigate to the Submissions area)
  2. Look for the Publications section
  3. Tap + to add a new publication
  4. Fill in details:
  5. Name: The Moth Magazine
  6. Type: Magazine
  7. URL: https://themothmagazine.com
  8. Notes: Accepts 6 poems max, responds in 3–6 months, no simultaneous submissions
  9. Tap Create

Create a Competition

  1. Tap + again
  2. Fill in:
  3. Name: National Poetry Competition
  4. Type: Competition
  5. URL: https://nationalpoetryday.co.uk/competition
  6. Notes: Max 40 lines, entry fee £7, deadline 31 October
  7. Deadline: Set the actual deadline date
  8. Tap Create

Set a Deadline Reminder

For the competition, set a reminder so you don't miss the deadline:

  1. Open the National Poetry Competition publication
  2. Tap Set Deadline Reminder
  3. Choose when to be reminded (e.g., 2 weeks before deadline)
  4. You'll receive a system notification at the chosen time

Tip: Create entries for all the publications you regularly submit to. The notes field is perfect for remembering submission guidelines, response times, and past experiences.

Step 2: Prepare a Submission Collection

For poetry submissions, the recommended workflow is to create a collection of the poems you want to submit together.

Create a Submission Collection

  1. Open the Collections folder
  2. Tap +
  3. Name it: "Moth Submission – Feb 2026"
  4. Add a synopsis: "6 poems on the theme of memory"
  5. Tap Create

Add Poems

  1. Open the Poems folder
  2. Tap Edit
  3. Select the 6 poems you want to submit
  4. Tap Add to Collection
  5. Select "Moth Submission – Feb 2026"

Order the Poems

  1. Open the collection
  2. Tap Edit
  3. Drag poems into your preferred reading order
  4. Tap Done

The order matters — it's how the editor will read them. Put your strongest poem first.

Step 3: Create a Submission

Now record the actual submission:

  1. Open the collection "Moth Submission – Feb 2026"
  2. Tap Submit to Publication
  3. Select The Moth Magazine
  4. Confirm the submission details:
  5. Submitted Date: Today (auto-filled)
  6. Files: The 6 poems in the collection
  7. Tap Submit

Writing Shed Pro records: - Which poems (and which versions) were submitted - The date of submission - The target publication - The initial status: Pending

Step 4: Set a Follow-Up Reminder

Most publications take weeks or months to respond. Set a reminder so you don't forget:

  1. Open the submission you just created
  2. Tap Set Reminder
  3. Choose a date (e.g., 3 months from now, based on their typical response time)
  4. The system will send you a notification when the reminder fires

This is especially useful when you have submissions at multiple publications — the reminders keep track so you don't have to.

Step 5: Track Submission Status

When you hear back, update the status:

If Accepted

  1. Open the submission
  2. Change status to Accepted
  3. Add notes: which poems were accepted, publication date, payment details
  4. Save

If Rejected

  1. Open the submission
  2. Change status to Rejected
  3. Add notes: any feedback received, whether to resubmit elsewhere
  4. Save

If You Withdraw

If you withdraw the submission (perhaps a poem was accepted elsewhere): 1. Open the submission 2. Change status to Withdrawn 3. Add notes explaining why 4. Save

Step 6: Handle Simultaneous Submissions

Many writers submit the same work to multiple publications at once. Here's how to manage that:

Check Each Publication's Policy

Review your publication notes — some publications don't allow simultaneous submissions. The notes field you filled in earlier is your reference.

Submit to Multiple Publications

  1. Create separate submissions for each publication
  2. Each submission links to the same poems (or collection)
  3. Track status independently for each

When One Accepts

If a publication accepts work that you also submitted elsewhere: 1. Update the accepted submission to Accepted 2. Open the other submissions containing the same poems 3. Update those to Withdrawn 4. Add a note: "Withdrawn — accepted by [Publication Name]"

Step 7: View Your Submission History

To see all submissions at a glance:

  1. Open the Submissions folder
  2. See all submissions listed with:
  3. Publication name
  4. Submission date
  5. Current status
  6. Number of files included

Filtering by Status

You can see: - Pending: Work still out for consideration - Accepted: Successfully placed work - Rejected: Declined submissions - Withdrawn: Submissions you pulled back

This history builds over time into a complete record of your submission activity.

Step 8: Submit Again After Rejection

Rejection is part of writing. When a piece comes back:

  1. Review any feedback from the rejection
  2. Decide: revise the work, or submit as-is to another publication?
  3. If submitting elsewhere, create a new submission from the collection (or create a new collection if the selection has changed)
  4. Record the new submission

Over time, your submission history shows each piece's journey from draft to publication.

Complete Workflow Summary

Here's the full submission lifecycle:

1. Write poems → mark as Ready
2. Create a Collection → add poems
3. Set up Publication → add notes and guidelines
4. Submit to Publication → status: Pending
5. Set a follow-up Reminder
6. Wait...
7. Hear back → update status:
   ├── Accepted → celebrate, withdraw other subs
   ├── Rejected → revise or resubmit elsewhere
   └── No response → reminder fires → follow up

What You've Learned

  • Setting up publications with contact info and guidelines
  • Creating Poetry Collections for submission packages
  • Recording submissions linked to specific files and publications
  • Tracking submission status through its lifecycle
  • Setting notification reminders for follow-ups and deadlines
  • Managing simultaneous submissions responsibly
  • Building a submission history

Tips for Submissions

  • Keep notes current: Update publication entries when guidelines change
  • Name collections clearly: Include the publication name and date for easy reference
  • Set reminders generously: Better to check early than to forget
  • Track everything: Even rejections are valuable data over time
  • Version matters: Submissions record which version was sent — if you revise after submitting, the original sent version is preserved
