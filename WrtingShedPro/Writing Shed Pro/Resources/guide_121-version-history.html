Version History

A record of Writing Shed Pro releases and their major changes.

Current Version

Version 1.0

Release Date: 2025

The initial public release of Writing Shed Pro.

Features:
  • Four project types: Prose, Poetry, Fiction, Drama
  • iCloud sync across devices
  • iOS/iPadOS 17+ and macOS 14+ support
  • Full-featured text editor
  • Stylesheet customization
  • PDF and RTF export
  • Poetry tools: syllable counting, rhyme detection, verse highlighting
  • Fiction tools: chapters, scenes, plot tracking
  • Drama tools: DML script formatting
  • Collections for organizing work
  • Submission tracking for publications
  • Comments and footnotes
  • Word count and statistics
  • Keyboard shortcuts for Mac and iPad

Future Versions

Updates will be documented here as they're released.

Understanding Version Numbers

Writing Shed Pro uses semantic versioning:

Major.Minor.Patch
  • Major: Significant new features or changes
  • Minor: New features, backward compatible
  • Patch: Bug fixes and small improvements

Example: Version 1.2.3

  • Major version: 1
  • Minor version: 2
  • Patch version: 3

Checking Your Version

On iPhone/iPad

  • Open Writing Shed Pro
  • Go to Settings
  • Scroll to About or Version

    • On Mac

  • Open Writing Shed Pro
  • Menu: Writing Shed Pro → About

    • Updating the App

    Automatic Updates

    Enable automatic updates in App Store settings to always have the latest version.

    Manual Update

  • Open the App Store
  • Search for Writing Shed Pro
  • If an update is available, tap Update
