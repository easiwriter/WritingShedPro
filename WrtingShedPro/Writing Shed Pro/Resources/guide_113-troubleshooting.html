Troubleshooting

Solutions to common issues in Writing Shed Pro.

Sync Issues

Files Not Syncing

Symptoms: Changes on one device don't appear on another. Solutions:
  • Check internet connection on both devices
  • Ensure iCloud is enabled in Settings
  • Wait a few minutes—sync isn't instant
  • Force quit and reopen the app
  • Check iCloud storage isn't full
  • Verify same Apple ID on both devices

    • Sync Conflicts

    Symptoms: Message about conflicts; duplicate files. Solutions:
  • Review both versions
  • Keep the correct one
  • Delete the duplicate
  • In future, wait for sync before switching devices

    • "Unable to Sync" Error

    Solutions:
  • Check internet connection
  • Check iCloud status at apple.com/support/systemstatus
  • Sign out and back into iCloud
  • Restart device
  • Wait and try again later

    • App Performance

    App Running Slowly

    Solutions:
  • Close other apps
  • Restart the app
  • Restart your device
  • Check available storage space
  • Large projects may need more time

    • App Crashes

    Solutions:
  • Update to latest app version
  • Update iOS/macOS
  • Restart device
  • If persists, contact support with steps to reproduce

    • App Won't Open

    Solutions:
  • Force quit and try again
  • Restart device
  • Check for app updates
  • Reinstall the app (your data is in iCloud)

    • Editing Issues

    Text Not Appearing

    Solutions:
  • Check zoom level (⌘0 to reset)
  • Check text color vs background color
  • Scroll to cursor position
  • Force quit and reopen

    • Formatting Lost

    Solutions:
  • Undo (⌘Z) immediately
  • Check file version history
  • Formatting might be in style, not inline

    • Undo Not Working

    Solutions:
  • Undo has limits—can't undo everything
  • After save/close, undo resets
  • Check file versions for recovery

    • Cursor Jumping

    Solutions:
  • May be auto-scroll behavior
  • Check for accidental touches
  • Disable autocorrect if it's interfering

    • Export and Print Issues

    PDF Looks Wrong

    Solutions:
  • Check Page Setup settings
  • Preview in Pagination View before export
  • Check font availability
  • Try different export options

    • Print Problems

    Solutions:
  • Check printer is connected
  • Check paper size matches Page Setup
  • Check printer margins
  • Try Print to PDF first to verify

    • Export Fails

    Solutions:
  • Check available storage
  • Try exporting to a different location
  • Check permissions on destination folder
  • Try smaller file/fewer pages

    • iCloud Issues

    Can't Enable iCloud

    Solutions:
  • Sign into iCloud in device Settings
  • Ensure iCloud Drive is enabled
  • Ensure app is allowed to use iCloud
  • Check iCloud storage isn't full

    • Files Missing

    Solutions:
  • Check Trash within app
  • Check Recently Deleted in Files app
  • Check iCloud Drive in Files app
  • Files may still be downloading

    • Files Stuck Downloading

    Solutions:
  • Tap to force download
  • Check internet connection
  • Check iCloud storage
  • Wait—large files take time

    • Poetry Features

    Syllable Count Wrong

    Solutions:
  • Check word pronunciation
  • Custom words may need dictionary additions
  • Some words have multiple valid counts
  • Trust your ear for edge cases

    • Rhyme Not Detected

    Solutions:
  • Check spelling of both words
  • Some rhymes are imperfect/slant
  • Proper nouns may not be in dictionary
  • Regional pronunciation differences

    • Fiction Features

    Scenes Not Linking

    Solutions:
  • Check both scene and plot element exist
  • Link from scene settings
  • Save after making links

    • Word Count Wrong

    Solutions:
  • Count may exclude certain text
  • Check settings for what's counted
  • Footnotes/comments may be separate

    • Drama Features

    DML Not Formatting

    Solutions:
  • Check prefix syntax (>` for action, etc.)
  • Character names must be ALL CAPS
  • Check for extra spaces
  • View in Preview to debug

    • Output Format Wrong

    Solutions:
  • Check Film vs Stage setting
  • Settings are per-project
  • Toggle and toggle back if stuck

    • Recovery

    Lost Work

    Solutions:
  • Check undo history
  • Check file versions (if available)
  • Check other devices for synced versions
  • Check Time Machine backup (Mac)
  • iCloud keeps some file versions

    • Deleted File Recovery

  • Check Trash in app
  • Empty Trash must be confirmed
  • iCloud may retain deleted files briefly
  • Contact Apple Support for iCloud recovery

    • Getting More Help

    Collect this information:

    • Device model and OS version
    • App version
    • Steps to reproduce issue
    • Screenshots or screen recordings
    • Error messages (exact text)
