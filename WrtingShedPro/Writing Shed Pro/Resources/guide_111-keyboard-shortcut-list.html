Keyboard Shortcut List

A complete reference of keyboard shortcuts available in Writing Shed Pro. Works on Mac and iPad with external keyboard.

File Operations

Shortcut Action
⌘N New file
⌘S Force save/sync
⌘W Close file

Edit Operations

Shortcut Action
⌘Z Undo
⌘⇧Z Redo
⌘X Cut
⌘C Copy
⌘V Paste
⌘A Select all
⌫ (Delete) Delete selection or character left
⌦ (Forward Delete) Delete character right

Text Formatting

Shortcut Action
⌘B Bold
⌘I Italic
⌘U Underline

Styles

Shortcut Action
⌘⌥0 Apply Body style
⌘⌥1 Apply Heading 1
⌘⌥2 Apply Heading 2
⌘⌥3 Apply Heading 3

Find and Replace

Shortcut Action
⌘F Open Find
⌘G Find next
⌘⇧G Find previous
⌘⌥F Open Find and Replace
Esc Close Find/Replace

Navigation

Shortcut Action
⌘↑ Go to document start
⌘↓ Go to document end
⌘← Go to line start
⌘→ Go to line end
⌥← Move word left
⌥→ Move word right
⌥↑ Move paragraph up
⌥↓ Move paragraph down
⇞ (Page Up) Scroll up one screen
⇟ (Page Down) Scroll down one screen

Selection

Shortcut Action
⇧ + any arrow Extend selection in that direction
⌘⇧← Select to line start
⌘⇧→ Select to line end
⌘⇧↑ Select to document start
⌘⇧↓ Select to document end
⌥⇧← Select word left
⌥⇧→ Select word right
⌥⇧↑ Select paragraph up
⌥⇧↓ Select paragraph down
⌘A Select all

Zoom

Shortcut Action
⌘+ or ⌘= Zoom in
⌘- Zoom out
⌘0 Reset zoom to 100%

Text Entry

Shortcut Action
Return New paragraph
⇧Return Line break (soft return)
Tab Insert tab (in code/tables)
⌘⇧C Insert comment
⌘⇧X Add index entry

Lists and Indentation

Shortcut Action
Tab Increase list indent (create sub-list)
⇧Tab Decrease list indent (promote item)

Notes: - Tab/Shift+Tab work when cursor is in a list item - Sub-lists use different numbering: 1→a→i for numbers, •→◦→▪ for bullets
- Sub-list numbering restarts when you return to a higher level - Shift+Tab at Level 1 exits the list (applies Body style)

Gestures (Touch)

iPhone

Gesture Action
Shake Undo
Three-finger swipe left Undo
Three-finger swipe right Redo
Double-tap word Select word
Triple-tap Select paragraph

iPad

Gesture Action
Three-finger swipe left Undo
Three-finger swipe right Redo
Double-tap word Select word
Triple-tap Select paragraph
Pinch Zoom in/out
Two-finger tap Secondary click (context menu)

Mac (Trackpad)

Gesture Action
Two-finger tap Secondary click
Pinch Zoom in/out
Force click Look up definition
