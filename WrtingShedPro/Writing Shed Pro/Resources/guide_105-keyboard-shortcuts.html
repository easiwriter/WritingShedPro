Keyboard Shortcuts

Writing Shed Pro supports keyboard shortcuts for faster navigation and editing. These work on Mac and iPad with an external keyboard.

Viewing All Shortcuts

On iPad with keyboard: - Press and hold ⌘ (Command) to see available shortcuts for the current screen

On Mac: - Shortcuts appear in menus next to commands - Hold ⌘ for context-specific shortcuts

Essential Shortcuts

File Operations

Shortcut Action
⌘N New file
⌘S Save (auto-saves, but forces sync)
⌘W Close file

Edit Operations

Shortcut Action
⌘Z Undo
⌘⇧Z Redo
⌘X Cut
⌘C Copy
⌘V Paste
⌘A Select all

Text Formatting

Shortcut Action
⌘B Bold
⌘I Italic
⌘U Underline

Find and Replace

Shortcut Action
⌘F Find
⌘G Find next
⌘⇧G Find previous
⌘⌥F Find and replace

Navigation

Shortcut Action
⌘↑ Go to document start
⌘↓ Go to document end
⌘← Go to line start
⌘→ Go to line end
⌥← Move word left
⌥→ Move word right

Selection

Shortcut Action
⇧ + arrow Extend selection
⌘⇧← Select to line start
⌘⇧→ Select to line end
⌘⇧↑ Select to document start
⌘⇧↓ Select to document end
⌥⇧← Select word left
⌥⇧→ Select word right

Zoom

Shortcut Action
⌘+ Zoom in
⌘- Zoom out
⌘0 Reset zoom

Text Insertion Shortcuts

Shortcut Action
⌘⇧C Insert comment (if available)
Return New paragraph
⇧Return Line break (within paragraph)

Special Keys

Common Modifier Keys

  • ⌘ (Command): Primary modifier
  • ⌥ (Option/Alt): Secondary modifier
  • ⇧ (Shift): Extend selection or alternate action
  • ⌃ (Control): Additional options

Function Keys (if keyboard has them)

May be available for custom actions.

Platform Differences

iPad with External Keyboard

  • Most shortcuts work
  • Some Mac-specific shortcuts may differ
  • Hold ⌘ to see available options

Mac

  • Full keyboard support
  • Menu bar shows shortcuts
  • System shortcuts also available

iPhone

No hardware keyboard typically, but Bluetooth keyboards work similarly to iPad.

Customizing Shortcuts

Currently, shortcuts are not customizable. The defaults follow Apple's standard patterns.

Learning Shortcuts

Start with the Essentials

Learn these first: 1. ⌘B/I/U (formatting) 2. ⌘Z (undo) 3. ⌘F (find) 4. ⌘C/V (copy/paste)

Build from There

Add shortcuts as you need them. Muscle memory develops over time.

Print a Reference

See Keyboard Shortcut List for a printable list.

Troubleshooting

Shortcut Not Working

  • Check correct keys pressed
  • Some shortcuts are context-sensitive
  • Feature may not be available in current view

Wrong Action Happening

  • May be conflicting with system shortcut
  • Check the intended shortcut
  • Report bugs if shortcuts behave unexpectedly
