Quick Start Guide

Get writing in Writing Shed Pro in just five minutes. This guide walks you through creating your first project and writing your first document.

Step 1: Create a Project

When you first open Writing Shed Pro, you'll see an empty project list.

  • Tap the + button in the toolbar
  • Enter a name for your project (e.g., "My First Project")
  • Choose a project type:

    • - Prose for general writing

    - Poetry for poems and verse

    - Fiction for stories and novels

    - Drama for scripts and plays

  • Tap Create

    • Your new project appears in the list. Tap it to open.

    Step 2: Understand the Folder Structure

    Every project starts with a standard folder structure:

    • Draft – Works in progress
    • Ready – Completed pieces
    • Set Aside – Items you're not currently working on
    • Trash – Deleted items (can be restored)

    Poetry and short fiction projects also include:

    • Collections – Groups of files for organization
    • Publications – Magazines and competitions you submit to
    • Submissions – Track what you've sent where

    Step 3: Create Your First File

  • Tap the Draft folder to open it
  • Tap the + button
  • Enter a title for your file
  • Tap Create

    • The file opens automatically in the editor.

    Step 4: Write!

    Start typing. The editor works like any word processor:

    • Type naturally with the on-screen keyboard (iOS) or physical keyboard (Mac)
    • Text auto-saves as you type
    • Use the formatting toolbar above the keyboard for styling

    Basic Formatting

    The formatting toolbar provides quick access to:

    • ¶ – Change paragraph style (Body, Heading, etc.)
    • B – Bold
    • I – Italic
    • U – Underline
    • S̶ – Strikethrough
    • ⊕ – Insert menu (images, footnotes, comments)

    Step 5: Save Your Work

    Writing Shed Pro auto-saves continuously. Every change is preserved automatically:

    • Changes sync to iCloud within seconds
    • Your work is always backed up
    • No "Save" button needed

    To see your save history, look at file versions in the file details view.

    Step 6: Organize Your Work

    As you write more, keep things organized:

    Move Files Between Folders

  • Long-press a file
  • Choose Move to...
  • Select the destination folder

    • Create Subfolders

  • In any folder, tap +
  • Choose New Folder
  • Enter a name

    • Reorder Files

  • Tap Edit in the file list
  • Drag files using the handle on the right
  • Tap Done

    • What's Next?

    You've learned the basics! Here's where to go next:

    • The Interface Tour – Explore all the views and controls
    • Text Formatting – Master styles and formatting
    • Poetry Mode Overview – If you're a poet
    • Fiction Mode Overview – If you're writing fiction

  • Use iCloud – Enable iCloud sync in Settings for seamless multi-device access
  • Explore project types – Each type has specialized features worth trying
  • Learn the keyboard shortcuts – They'll speed up your workflow significantly
  • Check the reference section – Quick answers when you need them

    Installation

    Writing Shed Pro is available on iPhone, iPad, and Mac through the App Store. This guide covers installation and initial setup.

    System Requirements

    iPhone and iPad

    • iOS 17.0 or later
    • iPadOS 17.0 or later
    • Works on all supported iPhone and iPad models

    Mac

    • macOS 14.0 (Sonoma) or later
    • Mac Catalyst app (same app as iOS)
    • Works on Apple Silicon and Intel Macs

    Installing from the App Store

  • Open the App Store on your device
  • Search for "Writing Shed Pro"
  • Tap Get (or the price button)
  • Authenticate with Face ID, Touch ID, or your Apple ID password
  • Wait for the download to complete

    • The app icon appears on your Home Screen (iOS/iPadOS) or in Applications (Mac).

    First Launch

    When you first open Writing Shed Pro:

  • iCloud Permission: The app requests permission to use iCloud. We recommend enabling this for:

    • - Automatic backup of all your work

    - Seamless sync between your devices

    - No data loss if you lose or replace a device

  • Notifications: Optional push notifications for submission reminders and deadlines
  • Empty Project List: You'll see an empty project list, ready for you to create your first project

    • iCloud Setup

    Writing Shed Pro uses iCloud to store and sync your projects. To ensure this works:

  • Sign in to iCloud: Settings → [Your Name] → iCloud
  • Enable iCloud Drive: Settings → [Your Name] → iCloud → iCloud Drive: On
  • Enable Writing Shed Pro: Settings → [Your Name] → iCloud → Apps Using iCloud → Writing Shed Pro: On

    • Without iCloud

    You can use Writing Shed Pro without iCloud:

    • Projects are stored locally on your device
    • No sync between devices
    • Risk of data loss if device is lost or damaged
    • We strongly recommend enabling iCloud

    Updating the App

    Writing Shed Pro updates automatically if you have automatic updates enabled. To update manually:

  • Open the App Store
  • Tap your profile icon in the top right
  • Scroll down to see available updates
  • Tap Update next to Writing Shed Pro

    • Reinstalling

    If you delete and reinstall Writing Shed Pro:

    • With iCloud enabled: All your projects will sync back automatically
    • Without iCloud: Your local projects will be lost

    Multiple Devices

    Writing Shed Pro works across all your Apple devices:

  • Install on each device using the same Apple ID
  • Ensure iCloud is enabled on all devices
  • Your projects appear automatically on each device
  • Changes sync within seconds

    • Sync Conflict Resolution

    If you edit the same file on two devices simultaneously:

    • The most recent changes are preserved
    • Earlier changes are saved as a version
    • No data is ever lost

    Troubleshooting Installation

    App Won't Download

    • Check your internet connection
    • Ensure you have enough storage space
    • Try restarting the App Store (swipe up to close, reopen)
    • Restart your device

    App Won't Open

    • Try force-quitting and reopening
    • Restart your device
    • Delete and reinstall the app (if iCloud is enabled, no data is lost)

    iCloud Sync Not Working

    See iCloud Sync for detailed troubleshooting.

    iCloud Sync

    Writing Shed Pro uses iCloud to keep your projects synchronized across all your Apple devices. This guide explains how sync works and how to troubleshoot issues.

    How iCloud Sync Works

    When you enable iCloud:

    • All projects are stored in iCloud Drive
    • Changes sync automatically within seconds
    • Your work is backed up continuously
    • Devices must be signed into the same Apple ID

    What Syncs

    • All projects and their contents
    • Folder structure
    • File content and formatting
    • Images embedded in documents
    • Version history
    • Settings and preferences

    What Doesn't Sync

    • Local cache and temporary files
    • Undo history beyond the current session

    Enabling iCloud

    Check iCloud Status

  • Open Settings (iPhone/iPad) or System Settings (Mac)
  • Tap your Apple ID at the top
  • Tap iCloud
  • Ensure iCloud Drive is On
  • Scroll down and ensure Writing Shed Pro is On

    • First-Time Setup

    When you first open Writing Shed Pro with iCloud enabled:

  • The app creates a container in iCloud Drive
  • Existing projects (if any) upload to iCloud
  • Projects from other devices appear automatically

    • Syncing Multiple Devices

    For seamless sync across devices:

  • Install Writing Shed Pro on each device
  • Sign into the same Apple ID on all devices
  • Enable iCloud Drive on all devices
  • Enable Writing Shed Pro in iCloud settings on all devices

    • Sync Speed

    • Local changes are saved instantly
    • Cloud sync typically completes within seconds
    • Large files (with many images) may take longer
    • Wi-Fi is faster than cellular

    Working Offline

    Writing Shed Pro works fully offline:

    • All recent projects are available locally
    • You can read and edit without internet
    • Changes are queued for sync
    • When you reconnect, changes upload automatically

    Offline Indicators

    • A cloud icon may indicate pending sync
    • Check the project list for sync status

    Conflict Resolution

    If you edit the same file on two devices before sync completes:

  • Both versions are preserved: No data is lost
  • Most recent wins: The latest change becomes the current version
  • Other changes saved: Earlier changes are available in version history

    • Avoiding Conflicts

    • Wait a few seconds after editing before switching devices
    • Ensure sync has completed (no pending upload indicators)
    • If in doubt, wait for the cloud icon to clear

    Managing iCloud Storage

    Projects count toward your iCloud storage quota.

    Check Usage

  • Settings → [Your Name] → iCloud → Manage Account Storage
  • Look for Writing Shed Pro

    • Reducing Usage

    • Delete old projects you no longer need
    • Empty the Trash in each project
    • Export and archive completed work

    Turning Off iCloud

    If you need to disable iCloud sync:

    Warning: This will remove Writing Shed Pro data from iCloud. Projects on other devices may no longer be accessible.
  • Settings → [Your Name] → iCloud → Apps Using iCloud
  • Toggle Writing Shed Pro Off
  • Choose whether to keep or delete local copies

    • Troubleshooting

    Projects Not Appearing

  • Verify you're signed into the correct Apple ID
  • Check that iCloud Drive is enabled
  • Check that Writing Shed Pro is enabled in iCloud settings
  • Wait a few minutes for initial sync
  • Check internet connection
  • Restart the app

    • Sync Seems Slow

  • Check your internet connection speed
  • Large projects with many images take longer
  • Initial sync of a new device may take time
  • Try switching from cellular to Wi-Fi

    • Changes Not Syncing

  • Check for a cloud icon indicating pending upload
  • Ensure the device has internet access
  • Force-quit and reopen the app
  • Restart the device
  • Check iCloud system status at apple.com/support/systemstatus

    • "This file is being edited on another device"

    This message appears when there's a potential conflict:

  • Save your work
  • Wait a moment for sync
  • Reload the file
  • Your changes and the other device's changes will both be preserved

    • Recovering Lost Data

    If data appears to be missing:

  • Check iCloud.com in a web browser
  • Look in iCloud Drive → Writing Shed Pro
  • Check the Trash folder in your projects
  • Restore from iCloud backup if necessary

    • Privacy and Security

    Your writing in iCloud is protected by:

    • End-to-end encryption in transit
    • Encryption at rest on Apple servers
    • Your Apple ID password
    • Optional two-factor authentication (highly recommended)

    Writing Shed Pro never has access to your Apple ID password. All sync is handled securely by the system.

    Project Settings

    Every project has settings that control its behavior and appearance. This guide explains what you can configure and how.

    Accessing Project Settings

  • Open a project
  • Tap the gear icon in the toolbar, or
  • Tap the project name and select Settings

    • General Settings

    Project Name

    • Change the project's display name
    • Tap the current name to edit
    • Changes sync immediately across devices

    Project Details

    • Add a description or notes about the project
    • Use for:

    - Synopsis or pitch

    - Notes to yourself

    - Project goals or deadlines

    - Any reference information

    Date Information (Read-Only)

    • Created: When the project was first created
    • Modified: When any content was last changed

    Project Type (Read-Only)

    The project type is shown but cannot be changed after creation. This includes:

    • Project type (Prose, Poetry, Fiction, Drama)
    • Fiction class (Novel or Short Fiction) for fiction projects

    If you need a different project type, create a new project and move your content.

    Story Structure (Fiction and Drama)

    For Fiction and Drama projects, you can change the story structure at any time:

  • Open Project Settings
  • Tap Story Structure
  • Choose from:

    • - Freeform: No predefined stages

    - Three-Act: 3 stages (Setup, Confrontation, Resolution)

    - Monomyth (Vogler): 12 stages from The Writer's Journey

    - Monomyth (Campbell): 17 stages from The Hero with a Thousand Faces

    Changing Structure

    When you change the structure:

    • Existing plot elements keep their stage assignments if the stage exists in the new structure
    • Plot elements assigned to stages that don't exist in the new structure are moved to "Unassigned"
    • Scene content is not affected

    Script Format (Drama Only)

    For Drama projects, choose how scripts are formatted:

  • Open Project Settings
  • Tap Script Format
  • Choose:

    • - Film/Screenplay: Industry-standard screenplay format

    - Stage Play: Traditional stage script format

    This affects how Drama Markup Language (DML) is rendered, not how you write it.

    Stylesheet

    Each project has a stylesheet that defines text formatting:

  • Open Project Settings
  • Tap Stylesheet
  • View and edit paragraph styles

    • See Stylesheet Editor for details.

    Page Setup

    Configure how pages are formatted for export and printing:

  • Open Project Settings
  • Tap Page Setup
  • Configure:

    • - Paper size (Letter, A4, etc.)

    - Orientation (Portrait, Landscape)

    - Margins

    - Headers and footers

    See Page Setup for details.

    Folders and Files

    Writing Shed Pro organizes your work in a hierarchy of folders and files within each project. This guide explains how to work with both.

    Understanding the Hierarchy

    Project

    └── Folders
    

        └── Subfolders (optional)
    

            └── Files
    • Projects contain folders
    • Folders contain files and other folders
    • Files contain your actual writing

    System Folders

    Each project type comes with predefined system folders that cannot be deleted:

    All Project Types

    • Draft: Work in progress
    • Ready: Completed pieces
    • Set Aside: Items you're not actively working on
    • Trash: Deleted items (restorable)

    Poetry and Short Fiction

    Additional system folders:

    • Collections: Groups of related files
    • Publications: Magazines and competitions
    • Submissions: Track what you've sent

    Fiction (Novel)

    Additional system folders:

    • Chapters: Chapter containers
    • Plot Elements: Story beats
    • Characters: Character profiles
    • Locations: Setting definitions

    Creating Folders

    You can create custom subfolders within system folders:

  • Open a folder
  • Tap the + button
  • Select New Folder
  • Enter a name
  • Tap Create

    • Folder Naming

    • Use clear, descriptive names
    • Examples: "Nature Poems", "Chapter Drafts", "Research Notes"
    • Avoid special characters

    Creating Files

    Create a new file:

  • Open the destination folder
  • Tap the + button
  • Select New File (or specific type for Poetry/Fiction)
  • Enter a title
  • For Poetry: Optionally select a form template
  • Tap Create

    • The file opens automatically in the editor.

    File Types by Project

    • Prose: Text files

    Footnotes let you add supplementary information without interrupting the flow of your text. They're essential for academic writing, useful for annotations, and can add depth to fiction and poetry.

    Understanding Footnotes

    A footnote consists of two parts:

    • Writing Shed Pro numbers footnotes automatically.

  • Tap the ⊕ (Insert) button in the toolbar

  • Make your changes
  • Tap Save

  • Access Footnotes... from the menu
  • Find the footnote you want to edit
  • Tap to edit
  • Save your changes

  • Open the file menu
  • Select Footnotes...

    • The list shows:

    • Footnote number
    • Preview of content
    • Location in document

    Tap any footnote to jump to its marker in the text.

    Deleting a Footnote

    From the Text

  • Select the footnote marker
  • Press Delete/Backspace

    • From the Footnotes List

  • Open Footnotes...
  • Swipe left on the footnote
  • Tap Delete
  • Confirm

    • When you delete a footnote, remaining footnotes renumber automatically.

    Automatic Numbering

    Footnotes are numbered sequentially:

    • First footnote is ¹
    • Second is ²
    • And so on...

    Renumbering

    When you add or delete footnotes:

    • All numbers update automatically
    • References stay accurate
    • No manual renumbering needed

    Footnotes vs Endnotes

    Writing Shed Pro supports two display modes:

    Footnotes Mode

    • Notes appear at the bottom of the page where referenced
    • Traditional academic and book style
    • Better for frequent reference

    Endnotes Mode

    • All notes appear at the end of the document
    • Cleaner page layout
    • Common in some publication styles

    Switching Modes

  • Open document settings
  • Find Footnote Display
  • Choose Footnotes or Endnotes

    • The content doesn't change—only where it appears.

    Footnotes in Pagination View

    In pagination view (full-page layout):

    • Footnotes appear at page bottom
    • A separator line divides text from footnotes
    • Long footnotes may continue on the next page
    • Professional typesetting rules apply

    Pagination Rules

    • Minimum 2 lines of body text above footnotes
    • Long footnotes split with continuation
    • Proper spacing maintained

    Footnote Formatting

    • Typically smaller than body text

  • Save

    Creating Sub-Lists

    Using the Toolbar (iPhone/iPad):
  • Place cursor in a list item
  • Tap the Increase Indent button (→
    		• ) to create a sub-list
  • Tap the Decrease Indent button (
    		• ←) to promote an item back up
    Using Keyboard Shortcuts (External Keyboard):
    • Press Tab to increase indent level (create sub-list)
    • Press Shift+Tab to decrease indent level (promote item)

    How Numbering Works

    Each sub-list level uses a different numbering style:

    LevelNumbered StyleBullet Style
    11. 2. 3.• (bullet)
    2a. b. c.◦ (circle)
    3i. ii. iii.▪ (square)
    Important: Sub-list numbering restarts when you return to a higher level. For example: 
    1. First main item

       a. Sub-item under first
    

       b. Another sub-item
    

    2. Second main item
    

       a. Sub-item starts at 'a' again
    

       b. Because we're under a new parent

    1. Planning Phase

       a. Define objectives
    

       b. Identify stakeholders
    

          i. Internal team
    

          ii. External clients
    

       c. Set timeline
    

    2. Execution Phase
    

       a. Assign tasks
    

       b. Monitor progress

    Method 1 - Decrease Indent:

    • This applies the Body style
    Method 2 - Change Style:
    • Tap the ¶ button
    • Select Body or another non-list style
    Method 3 - Empty Line:
    • Press Return twice on an empty list item
    • The second Return may exit the list (behavior varies)

    • Plain text removes all formatting

    Headings and Styles

    Headings structure your document, making it easier to navigate and understand. Styles ensure consistent formatting throughout your work. This guide covers both.

    Understanding Headings

    Headings create a hierarchy in your document:

    Heading 1: Main Title

    ├── Heading 2: Section
    

    │   ├── Heading 3: Subsection
    

    │   └── Heading 3: Subsection
    

    └── Heading 2: Section

    When to Use Each Level

    LevelUse ForExamples
    Heading 1Main title, chapter titles"Chapter 1", "Introduction"
    Heading 2Major sections"Background", "Methods"
    Heading 3Subsections"Data Collection", "Analysis"

    Applying Headings

  • Place cursor in the paragraph you want as a heading
  • Tap the ¶ button in the toolbar
  • Select Heading 1, 2, or 3
  • The paragraph reformats as a heading

    • Heading Best Practices

    • Use headings in order (don't skip from H1 to H3)
    • Keep heading text concise
    • Use sentence case or title case consistently
    • Don't end headings with periods

    Understanding Styles

    A style is a saved set of formatting attributes. Instead of manually formatting each paragraph, you apply a style.

    Benefits of Styles

  • Consistency: All same-style paragraphs look identical
  • Efficiency: One tap applies multiple formats
  • Flexibility: Change a style to update all instances
  • Export-friendly: Styles translate well to other formats

    • Built-in Styles

    Writing Shed Pro includes these default styles:

    StylePurpose
    BodyRegular paragraph text
    Heading 1Primary headings
    Heading 2Secondary headings
    Heading 3Tertiary headings
    SubheadlineSubtitle or lead text
    CaptionImage captions, notes
    FootnoteFootnote content
    Block QuoteQuotations

    Applying Styles

  • Single paragraph: Tap in paragraph, select style
  • Multiple paragraphs: Select text spanning paragraphs, select style

    • Working with the Style Picker

    Tap ¶ to open the style picker:

    • Styles are listed by name
    • Current style is highlighted
    • Tap any style to apply it
    • Changes take effect immediately

    Customizing Styles

    You can modify any style to match your preferences:

  • Select text with the style you want to edit
  • Tap Edit Style from the selection menu
  • Adjust settings:

    • - Font family and size

    - Bold, italic, underline

    - Text color

    - Alignment

    - Spacing

  • Save your changes

    • Changes apply to all paragraphs using that style.

    See Stylesheet Editor for complete details.

    Creating New Styles

    If the built-in styles don't meet your needs:

  • Open the Stylesheet Editor
  • Tap Add Style (or + button)
  • Name your new style
  • Configure all attributes
  • Save

    • Your custom style appears in the style picker.

    Style Hierarchy

    Styles can inherit from other styles:

    • A style based on Body shares Body's attributes
    • Override only what's different
    • Changes to the parent affect children (unless overridden)

    This makes it easy to maintain consistent base formatting while varying specific elements.

    Document Structure with Headings

    Well-structured documents are easier to:

    • Navigate
    • Understand
    • Export to other formats
    • Convert to table of contents

    The Garden Novel

    ├── Part One: Spring

        ├── Chapter 4: Long Days
    

        └── Chapter 5: Heat Wave

    Each part title might be Heading 1, each chapter Heading 2.

    Rhyme Tools

    Rhyme is a fundamental element of many poetry forms. Writing Shed Pro provides tools to help you identify, plan, and execute rhyme schemes.

    Rhyme Scheme Display

    When working with a form that has a specific rhyme scheme:

    Viewing the Scheme

    • The expected rhyme scheme appears in the form reference panel
    • Each line is labeled (A, B, C, etc.)
    • Same letters should rhyme

    Example: Shakespearean Sonnet

    Line 1  (A)    When in disgrace with fortune and men's eyes

    Line 2  (B)    I all alone beweep my outcast state
    

    Line 3  (A)    And trouble deaf heaven with my bootless cries
    

    Line 4  (B)    And look upon myself and curse my fate
    

    ...
    

    Line 13 (G)    For thy sweet love remembered such wealth brings
    

    Line 14 (G)    That then I scorn to change my state with kings

    Types of Rhyme

    Writing Shed Pro recognizes various rhyme types:

    Perfect Rhyme

    Words with identical endings:

    • cat/hat
    • love/dove
    • night/light

    Near Rhyme (Slant Rhyme)

    Words with similar but not identical sounds:

    • love/move
    • eyes/light
    • moon/on

    Internal Rhyme

    Rhymes within a line:

    • "Once upon a midnight dreary, while I pondered, weak and weary"

    Finding Rhymes

    When you need rhyming words:

    Using Look Up

  • Select a word you need to rhyme with
  • Use the system Look Up feature
  • Explore dictionary and thesaurus options

    • Manual Approach

    Consider:

    • Perfect rhymes first
    • Slant rhymes for more options
    • Near rhymes for subtle effects

    Rhyme Scheme Tips

    Plan Ahead

    For complex schemes, sketch rhymes before writing:

  • Identify your end words for A lines
  • List possible B rhymes
  • Continue for each rhyme group

    • Avoid Forced Rhyme

    • Don't sacrifice meaning for rhyme
    • Slant rhymes are often better than awkward perfect rhymes
    • The best rhyme feels inevitable, not forced

    Consider End Sounds

    Some sounds offer more rhymes:

    • "ay" sounds (day, way, say, play...)
    • "ight" sounds (night, light, bright...)

    Difficult rhyming sounds:

    • "orange" (few true rhymes)
    • "month" (limited options)
    • "silver" (challenging)

    Rhyme in Different Forms

    Sonnets

    • Complex schemes require planning
    • 3 quatrains + couplet (Shakespearean)
    • Octave + sestet (Petrarchan)

    Villanelle

    • Only two rhyme sounds (A and B)
    • Repeated lines add structure
    • Plan carefully before writing

    Limerick

    • AABBA scheme
    • A lines typically longer
    • B lines short and punchy

    Free Verse

    • No required rhyme
    • Use rhyme for effect when desired
    • Internal rhyme creates subtle music

    Common Rhyming Challenges

    Overused Rhymes

    Avoid clichéd pairs:

    • love/dove/above
    • heart/apart
    • moon/June

    Inverted Syntax

    Don't twist sentences for rhyme:

    • "The house so white" ← awkward
    • "The white house" ← natural

    Rhyme Fatigue

    In long poems, vary:

    • Use slant rhymes occasionally
    • Place rhymes at unexpected spots
    • Give readers' ears a rest

    Building Your Rhyme Vocabulary

    Read Poetry

    Exposure builds your mental rhyme dictionary.

    Keep Lists

    Note good rhymes you discover.

    Practice

    Write exercises focusing on specific sounds.

    Thesaurus

    Find synonyms that offer better rhymes.

    DML Reference

    Drama Markup Language (DML) is Writing Shed Pro's lightweight markup for script writing. This reference covers all DML syntax elements.

    Design Philosophy

    DML is designed to be:

    • Human-readable: Easy to read and write
    • Minimal: Common elements require little decoration
    • Format-agnostic: Same source works for film and stage
    • Intuitive: Mirrors how you'd naturally write

    Quick Reference

    ElementSyntaxExample
    Scene Heading## INT. OFFICE - DAY
    CharacterALL CAPSJOHN
    DialogueLines after characterHello there.
    Parenthetical( ) after character(whispering)
    Action>> John enters.
    Transition>>>> CUT TO:
    Location@@ LOCATION: Office
    Time/Atmosphere== Night, rain
    Note[[ ]][[Check this scene]]

    Detailed Syntax

    Scene Headings

    Start a line with # for scene headings:

    # INT. COFFEE SHOP - DAY

    # EXT. BEACH - SUNSET
    

    # ACT II, Scene 3
    Film format: Include INT./EXT., location, time Stage format: Use ACT/Scene notation

    Character Names

    Write character names in ALL CAPS on their own line:

    JOHN

    MARY
    

    DR. SMITH
    

    OFFICER #1

    Everything following a character name (until another element) is their dialogue.

    Dialogue

    Lines following a character name are dialogue:

    JOHN

    I've been thinking about what you said.
    

    And I think you're right.

    Multiple lines of dialogue are fine—they'll be formatted together.

    Parentheticals

    Acting directions go in parentheses after the character name:

    JOHN

    (hesitantly)
    

    I don't know about this.
    


    MARY
    

    (turning away)
    

    Neither do I.

    Parentheticals can also appear mid-dialogue:

    JOHN

    I think I love you.
    

    (beat)
    

    No, I know I do.

    Action / Stage Directions

    Start with > for action or stage directions:

    > John crosses to the window and looks out at the rain.

    > Mary enters from the kitchen, carrying a tray.
    

    > The lights dim. Thunder rumbles in the distance.

    These render as:

    • Film: Full-width action paragraphs
    • Stage: Stage directions (often italicized)

    Transitions

    Start with >> for transitions:

    >> CUT TO:

    >> FADE OUT
    

    >> DISSOLVE TO:
    

    >> BLACKOUT

    These render as:

    • Film: Right-aligned transitions
    • Stage: Theatrical transitions (centered or as appropriate)

    Location Metadata

    Use @ for location information:

    @ LOCATION: Sarah's Apartment

    @ LOCATION: The Beach House

    This helps DML construct scene headings, especially for stage format.

    Time/Atmosphere

    Use = for time of day and atmospheric conditions:

    = Day

    = Night, stormy
    

    = Late afternoon, golden light
    

    = Morning, mist

    Combined with location:

    @ LOCATION: Office

    = Night, empty building

    Film renders as: INT. OFFICE - NIGHT

    Stage renders as: (An office. Night. The building is empty.)

    Notes

    Writer's notes that don't render in output:

    [[Remember to add more tension here]]

    [[Check with director about this scene]]
    

    [[TODO: Research police procedures]]

    Notes are for your reference only—they won't appear in exports.

    Complete Example

    # ACT I, Scene 1

    @ LOCATION: Living Room
    

    = Night, raining
    


    > A modest living room. Rain streaks the windows. JOHN stands 
    

    > near the window, agitated. A half-empty glass of whiskey 
    

    > sits on the side table.
    


    JOHN
    

    (to himself)
    

    She should be here by now.
    


    > He checks his watch, then resumes pacing.
    


    [[Consider cutting the whiskey reference]]
    


    > The door opens. MARY enters, soaking wet.
    


    MARY
    

    (shaking off rain)
    

    The roads are terrible.
    


    JOHN
    

    I was worried.
    


    MARY
    

    (softening)
    

    I know. I'm sorry.
    


    > She crosses to him. They embrace.
    


    >> BLACKOUT
    


    # ACT I, Scene 2
    

    @ LOCATION: Kitchen
    

    = The next morning
    


    > Bright sunlight. MARY makes coffee. JOHN enters in a robe.
    


    JOHN
    

    Did you sleep?
    


    MARY
    

    Not really.
    

    (beat)
    

    We need to talk about last night.
    


    >> END OF ACT ONE

    • Scene headings like INT. LIVING ROOM - NIGHT

    • Right-aligned transitions

    The same source renders with:

    • Scene headings like ACT I, Scene 1

    • Theatrical transitions

    Markdown Features

    Writing Shed Pro offers comprehensive Markdown support, including native Markdown editing, rich text preview, and import/export capabilities.

    What is Markdown?

    Markdown is a lightweight markup language that uses simple symbols to indicate formatting:

    • bold becomes bold
    • italic becomes italic
    • # Heading becomes a heading
    • link becomes a hyperlink

    Markdown files are plain text, readable by any text editor, yet carry formatting information that apps can interpret.

    Creating Markdown Files

    Writing Shed Pro lets you create and edit files in either Rich Text or Markdown mode. Markdown mode is ideal for writers who prefer plain text with simple formatting syntax.

    Switching Between Modes

    Any file can be switched between Rich Text and Markdown modes using the toggle button in the toolbar:

  • Open a file in the editor
  • Look for the content type toggle button in the toolbar:

    • - # icon (number square): Currently in Markdown mode - tap to switch to Rich Text

    - Document icon (richtext.page): Currently in Rich Text mode - tap to switch to Markdown

  • Tapping the button converts the content and switches mode
    • Note: Switching modes converts the content. Going from Rich Text to Markdown converts formatting to Markdown syntax. Going from Markdown to Rich Text renders the Markdown as formatted text.

    Markdown Mode Features

    When editing in Markdown mode:

    • A Markdown indicator bar appears at the bottom of the editor showing "Markdown"
    • Type using standard Markdown syntax
    • Tap the toggle button to preview your content as formatted Rich Text
    • All standard Markdown formatting is supported

    Previewing Markdown

    To see how your Markdown will look when rendered:

  • Tap the content type toggle button in the toolbar (switches to Rich Text mode)
  • Your Markdown is converted and displayed with:

    • - Headings rendered with appropriate sizes

    - Bold, italic, and other formatting applied

    - Links displayed as clickable text

  • Tap the toggle again to return to Markdown editing mode

    • The preview uses your project's stylesheet, so headings and text styles match your document formatting.

    When to Use Markdown Mode

    Markdown mode is particularly useful for:

    • Writers comfortable with Markdown syntax
    • Content destined for blogs or GitHub
    • Quick drafting without formatting distractions
    • Files you plan to export as Markdown
    Note: Markdown mode is not available for Poetry or Drama projects, which require specialized formatting features.

    Exporting to Markdown

    When to Use Markdown Export

    • Sharing with collaborators who use plain text editors
    • Publishing to platforms that accept Markdown (blogs, GitHub, etc.)
    • Creating backup copies in a universal format
    • Converting for use in other Markdown-based tools

    Why RTF?

    Advantages

    • Editable: Recipients can make changes
    • Compatible: Opens in Word, Pages, Google Docs, etc.
    • Standard: Long-established format

    • Sending to editors who need to make changes
    • Collaboration requiring editing
    • Importing into other applications
    • When PDF isn't accepted

    • Text content
    • Bold, italic, underline, strikethrough
    • Font family and size
    • Paragraph alignment
    • Line spacing
    • Basic colors

    Usually Preserved

    • Images (may resize)
    • Footnotes (may format differently)
    • Paragraph spacing
    • Indentation

    • Complex styles

    Appearance May Differ

    • Different apps render RTF differently
    • Pagination won't match exactly
    • Fonts may substitute if unavailable

    • Some formatting options don't translate
    • Complex layouts may simplify

    • Be flexible about final appearance

    Frequently Asked Questions

    Common questions about Writing Shed Pro.

    General

    What is Writing Shed Pro?

    Writing Shed Pro is a professional writing app for creative writers. It supports prose, poetry, fiction, and drama with specialized tools for each.

    What devices does it run on?

    • iPhone running iOS 17 or later
    • iPad running iPadOS 17 or later
    • Mac running macOS 14 (Sonoma) or later

    Do my files sync between devices?

    Yes. With iCloud enabled, your projects sync automatically across all your Apple devices.

    Is my data backed up?

    iCloud provides automatic backup. For extra safety, you can export important work as PDF or RTF.

    Can I use it offline?

    Yes. You can write offline. Changes sync when you reconnect.

    Projects

    What's the difference between project types?

    • Prose: General writing with no specialized tools
    • Poetry: Syllable counting, rhyme detection, verse tools
    • Fiction: Chapters, scenes, plot tracking
    • Drama: Script formatting with DML

    Can I change a project's type?

    No. Project type is set at creation. You can copy content to a new project of a different type.

    What are Draft, Ready, and Trash?

    • Draft: Work in progress
    • Ready: Finished work
    • Trash: Deleted files (can be recovered)

    How do I share a project?

    Export your project or individual files as PDF or RTF, then share using the standard share sheet.

    Writing

    Does it have spell check?

    Yes. The system spell checker is active while you write.

    Is there a word count goal?

    Word count is displayed but there's no built-in goal tracking.

    How do I add images?

    In the editor, use Insert → Image. You can add from Photos, Files, or Camera.

    Are footnotes supported?

    Yes. Insert footnotes through the Format menu or toolbar. They appear at page bottom.

    Poetry

    How accurate is the syllable counter?

    Very accurate for standard English. Some proper nouns and unusual words may need manual counting.

    What's the CMU dictionary?

    The Carnegie Mellon Pronouncing Dictionary provides pronunciation data for syllable counting and rhyme detection.

    Can I create my own poetry forms?

    You can select from built-in forms. Custom form creation may be added in future updates.

    Fiction

    How do chapters and scenes work?

    Scenes are individual files. Chapters are folders that contain scenes. You control the structure.

    What are plot elements?

    Plot elements (Setups, Conflicts, Resolutions) help you track story structure. Scenes can link to plot elements.

    Is there character management?

    Basic character notes are supported. Full character management may be added in future updates.

    Drama

    What is DML?

    Drama Markup Language—a simple way to write scripts using plain text that formats automatically.

    Can I export to Final Draft?

    Currently, exports are PDF and RTF. Industry-specific formats may be added later.

    Film or stage—which should I choose?

    Choose based on your target production. You can preview both formats from the same DML source.

    Export and Printing

    What formats can I export?

    • PDF (recommended for most uses)
    • RTF (Rich Text Format)

    Can I export to Word (.docx)?

    RTF exports can be opened in Word. Direct .docx export may be added later.

    How do I print?

    Use the standard Print option. Works on Mac and iPad with compatible printers.

    Sync and Storage

    How much iCloud storage do I need?

    Depends on your usage. Text uses minimal storage. Images use more. Most users need less than 1GB.

    Can I use it without iCloud?

    Yes, but sync between devices won't work. Your data stays on the device.

    I have a new device—where's my data?

    Sign into iCloud with the same Apple ID. Install Writing Shed Pro. Your projects will appear.

    Why is sync slow?

    First sync may take time. Large projects take longer. Poor internet slows sync. Wait and check again.

    Technical

    Can I access files in the Files app?

    Writing Shed Pro uses its own storage. Export files if you need them in Files.

    Does it work with external keyboards?

    Yes. Full keyboard shortcut support on iPad and Mac.

    Is there a web version?

    No. Writing Shed Pro is a native Apple app only.

    Can I use it on Windows or Android?

    No. It's exclusive to Apple platforms.

    Subscription and Purchase

    Is there a free trial?

    Check the App Store for current trial offerings.

    Is it a subscription or one-time purchase?

    Check the App Store for current pricing model.

    Can I get a refund?

    Contact Apple for App Store refunds.

    Contact support with detailed steps to reproduce the issue.

    Submit feature requests through the support channel.

    Is there a community forum?

    Check the app's website for community resources.

    Popular feature requests are considered for future updates. Submit yours through support.

    How often is the app updated?

    Regular updates address bugs and add features. Update notifications come through the App Store.

    Can I beta test new versions?
