EPUB Export

EPUB is a widely supported eBook format that works with Apple Books, Kindle (via conversion), Kobo, and most other e-readers. Use EPUB when you want to distribute your work digitally or read it on an e-reader.

Why EPUB?

Advantages

  • Reflowable: Text adapts to the reader's screen size and font preferences
  • Widely supported: Opens in Apple Books, Calibre, and most e-reader apps
  • Cover image: Includes your project's cover art if set
  • Lightweight: Compact file size for sharing and distribution

When to Use EPUB

  • Creating eBooks for personal reading or distribution
  • Sharing poetry collections or novels for on-screen reading
  • Preparing manuscripts for digital publication
  • When readers prefer reflowable text over fixed-layout PDF

Exporting to EPUB

EPUB export is available from the Manuscript view as a full-project export.

Manuscript Export

  1. Open your project
  2. Navigate to the Manuscript view
  3. Tap the Export button
  4. Select EPUB (eBook) from the format picker
  5. Choose where to save or how to share the file

The exported file is named ProjectName.epub.

What's Included

The EPUB contains your assembled manuscript — the same content you see in the Manuscript view:

  • Front matter (title page, copyright, etc.)
  • Body content (all included files, assembled by project type)
  • Back matter (endnotes, glossary, bibliography, index)

What's Preserved

Feature Preserved
Text content ✅
Bold, italic, underline, strikethrough ✅
Images ✅
Page breaks ✅
Cover image ✅ (if set in project settings)
Author metadata ✅
Poetry line breaks and stanza spacing ✅
Footnotes ✅

Differences from PDF

Unlike PDF, EPUB is a reflowable format. This means:

  • Page numbers, margins, and headers/footers from your page setup are not included — the reader app controls layout
  • Fonts may differ depending on the reader's settings
  • Text reflows to fit the screen, so line breaks in prose will change (poetry line breaks are preserved)

Cover Images

If your project has a cover image set, it is automatically included in the EPUB as the book cover. This appears in the reader's library view and as the opening page.

To set a cover image:

  1. Open Project Settings (⚙️)
  2. Tap Cover Image
  3. Select an image from your photo library

Poetry in EPUB

Poetry projects receive special treatment in EPUB export:

  • Line breaks are preserved exactly as written
  • Stanza breaks are maintained
  • Indentation is carried through
  • Each poem starts on a new page

This ensures your poems read correctly on any e-reader.

Reading Your EPUB

On Apple Devices

Open the EPUB file directly — it opens in Apple Books automatically.

On Kindle

Amazon Kindle does not read EPUB directly. Use Calibre (free, desktop) to convert EPUB to MOBI or AZW3 format, or send the EPUB to your Kindle via Amazon's Send to Kindle service which now accepts EPUB files.

On Other Devices

Most e-reader apps (Kobo, Google Play Books, etc.) support EPUB natively.

Troubleshooting

EPUB Won't Open

  • Ensure you're using an app that supports EPUB format
  • Try opening in Apple Books or Calibre to verify the file

Formatting Looks Different from PDF

  • This is expected — EPUB is reflowable, so the reader controls layout
  • If you need exact page layout, use PDF Export instead

Cover Image Not Showing

  • Check that a cover image is set in Project Settings
  • Some reader apps may not display covers for sideloaded EPUBs
